**Status:** 🏗 In Progress
**Epic:** Pixel Shmup (G009) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** เกมตรวจจับการชนระหว่างกระสุน-ศัตรู และศัตรู-เรือของฉัน  
**เพื่อให้** เกมตอบสนองต่อการกระทำและให้ผลลัพธ์ที่สม่ำเสมอ  

---

## ✅ Acceptance Criteria
1. [ ] กระสุนของผู้เล่นชนศัตรู → ศัตรูเสีย health หรือถูกทำลาย
2. [ ] ศัตรูชนเรือของผู้เล่น → ผู้เล่นเสีย health/life
3. [ ] ศัตรุต่อยิงกระสุนกลับมา (ถ้ามี) → กระทบเรือผู้เล่น
4. [ ] การชนทั้งหมดแสดง animation explosionเล็ก
5. [ ] ไม่มีการชนที่ผิดพลาด (hitbox ถูกต้อง)
