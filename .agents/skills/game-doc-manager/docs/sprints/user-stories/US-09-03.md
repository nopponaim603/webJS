# User Story: US-09-03 - Enemy Spawning Pattern

**Status:** 🏗 In Progress
**Epic:** Pixel Shmup (G009) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** ศัตรูถูก spawn จากด้านบนหน้าจอ  
**เพื่อให้** ฉันได้รับความท้าทายและถูกทดสอบ  

---

## ✅ Acceptance Criteria
1. [ ] ศัตรูถูก spawn จากด้านบน screen ในรูปแบบ pattern
2. [ ] Spawn interval เป็น interval 1.5-2 วินาที (เริ่มต้น)
3. [ ] ศัตรู 3 ประเภท:
   - Small: เร็ว, health 1
   - Medium: เร็วปานกลาง, health 2
   - Large: ช้า, health 5
4. [ ] ศัตรูเคลื่อนที่ลงมาทางล่าง (หรือตาม path เฉพาะ)
5. [ ] ศัตรูถูก destroy เมื่อ health 0 หรือ out of screen
