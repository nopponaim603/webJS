# User Story: US-09-02 - Shoot Bullets on Input

**Status:** 🏗 In Progress
**Epic:** Pixel Shmup (G009) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** ยิงกระสุนขึ้นด้านบนด้วย key fire หรือ tap  
**เพื่อให้** ฉันสามารถทำลายศัตรูได้  

---

## ✅ Acceptance Criteria
1. [ ] กด key fire (Space / Z / tap) เพื่อยิงกระสุนขึ้น
2. [ ] กระสุนเคลื่อนที่ขึ้นข้างบนด้วยความเร็วสม่ำเสมอ
3. [ ] ไม่สามารถยิงได้เรื่อยเกิน (cooldown 250ms)
4. [ ] ปรากฏ animation เมื่อยิง (muzzle flash หรือ particle)
5. [ ] ตัวกระสุนถูก destroy เมื่อออกนอก screen หรือ impact ศัตรู
