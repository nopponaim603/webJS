# User Story: US-08-05 - Game Restart and New Game Button

**Epic:** Card Memory Match (G008) - Sprint 01

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** กดปุ่ม "New Game" หรือ "Restart" เพื่อเริ่มเกมใหม่โดยไม่ต้อง reload หน้า  
**เพื่อให้** ฉันสามารถเล่นซ้ำได้ด้วยการสับเที่ยมใหม่  

---

## ✅ Acceptance Criteria
1. [ ] ปุ่ม "New Game" ปรากฏใน HUD ระหว่างเกม
2. [ ] กดปุ่มจะ reset game state และ shuffle ใบคาร์ที่ใหม่
3. [ ] moves counter และ timer ถูก reset เป็น 0
4. [ ] ไม่ต้อง reload หน้า browser
5. [ ] ทุกใบคาร์ที่ถูกสับเที่ยมใหม่ 100% (ไม่ซ้ำ layout เดิม 2 ครั้งติดกัน)

---

## 🛠 Technical Tasks (Git Log Updates)
- [ ] Add "New Game" button sprite in HUD
- [ ] Implement game reset function (shuffle, clear state)
- [ ] Reset timer and move counter to zero
- [ ] Verify Fisher-Yates shuffle produces different order
- [ ] Add keyboard shortcut (R = restart)
