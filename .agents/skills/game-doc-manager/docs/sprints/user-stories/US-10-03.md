# User Story: US-10-03 - Camera Follow Player Through Level

**Epic:** Pico-8 Platformer (G010) - Sprint 02

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** camera ตามทั้งศีลผู้เล่นขณะเคลื่อนที่ผ่าน level  
**เพื่อให้** ฉันเห็นหน้าจออย่างถูกต้อง  

---

## ✅ Acceptance Criteria
1. [ ] Camera follow player (Phaser.Camera)
2. [ ] Camera bounded (ไม่แสดงนอก screen ข้างนอก)
3. [ ] Camera scroll ตาม player (left/right/up/down ตาม layout)
4. [ ] Smooth camera movement (no stutter)
5. [ ] Player ไม่หายไปจาก screen (camera center)

---

## 🛠 Technical Tasks (Git Log Updates)
- [ ] Set up camera bounds (camera.bounds = level size)
- [ ] Enable camera follow (camera.follow(player))
- [ ] Add camera dead zone (camera.deadzone)
- [ ] Test camera movement with level boundaries
- [ ] Verify camera follows correctly when jumping
