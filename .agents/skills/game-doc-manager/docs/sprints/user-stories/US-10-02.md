## ✅ Acceptance Criteria
1. [ ] Tilemap แสดงผล background และ ground tile
2. [ ] Player สามารถยืนบน tile ได้ (gravity collision)
3. [ ] Player ไม่ตกผ่าน tile (collide with all sides)
4. [ ] Tile ออกแบบเป็น 1-level design (พื้นฐาน)
5. [ ] Tile ถูก load จาก Kenney Pico-8 Platformer asset
