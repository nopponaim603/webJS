# User Story: US-08-02 - Card Flip and Match Detection Logic

**Status:** 🏗 In Progress
**Epic:** Card Memory Match (G008) - Sprint 01
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** สามารถคลิกใบคาร์ที่ 2 ใบตัวตัวเอง เพื่อทดสอบว่าคู่ตรงกันหรือไม่  
**เพื่อให้** เกมสามารถตรวจจับการจับคู่ที่ถูกต้องและซ้ำขึ้นได้  

---

## ✅ Acceptance Criteria
1. [ ] ผู้เล่นคลิกใบคาร์ที่ได้ 1 ใบที่ละครั้ง
2. [ ] เมื่อคลิกใบคาร์ที่ครั้งที่ 2 ระบบจะตรวจจับการจับคู่
3. [ ] หากรูปแบบตรงกัน → ใบคาร์ที่คงอยู่ในสถานะ face-up
4. [ ] หากรูปแบบไม่ตรง → ใบคาร์ที่ทั้ง 2 หันกลับด้วย animation
5. [ ] ป้องกันการคลิกใบคาร์ที่ที่ถูก open อยู่แล้ว
6. [ ] ป้องกันการคลิกใบคาร์ที่ที่ match แล้ว
