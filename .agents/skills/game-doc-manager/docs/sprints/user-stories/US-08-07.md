# User Story: US-08-07 - Performance Optimization & Loading

**Status:** 🏗 In Progress
**Epic:** Card Memory Match (G008) - Sprint 01
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** เกมโหลดเร็วและมี FPS สูง  
**เพื่อให้** ไม่มีความรู้สึกยืนยับหรือหน่วงขณะเล่น  

---

## ✅ Acceptance Criteria
1. [ ] Preload screen แสดงตอนโหลด assets ไม่นานกว่า 2 วินาที
2. [ ] Frame rate ไม่ต่ำกว่า 50 FPS บน desktop
3. [ ] Frame rate ไม่ต่ำกว่า 30 FPS บนมือถือกลางค่อนข้าง
4. [ ] ไม่มีการโหลดซ้ำ assets ซ้ำ
5. [ ] Memory usage ไม่เพิ่มขึ้นเรื่อยๆ เมื่อ play/restart
