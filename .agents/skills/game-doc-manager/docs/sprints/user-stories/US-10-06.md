# User Story: US-10-06 - Enemy NPC with Patrol AI

**Status:** 🏗 In Progress
**Epic:** Pico-8 Platformer (G010) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** เจอบัคที่เดินไปมาบนพื้น  
**เพื่อให้** ฉันได้รับ challenge ในการหลีกเลี่ยงหรือทำลาย  

---

## ✅ Acceptance Criteria
1. [ ] บัคถูก spawn บนพื้น level (ไม่ใช่ในอากาศ)
2. [ ] บัคเคลื่อนที่ไปทางซ้าย-ขวา แบบ patrol
3. [ ] บัคเปลี่ยนทิศทางเมื่อชน tile edge หรือ wall
4. [ ] Player ชนบัค → Player เสีย health (1 hit)
5. [ ] Player กระโดดลงบนบัค → บัคถูก destroy
6. [ ] บัค animation walk (back-and-forth)

---

## 🛠 Technical Tasks (Git Log Updates)

- [ ] Add jump-on-top kill mechanic (player velocity.y check)
- [ ] Add NPC animation frames
- [ ] Test NPC patrol path and collision
