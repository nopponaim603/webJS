# User Story: US-10-07 - Win Condition (Reach Flag/Goal) and Game Over

**Status:** 🏗 In Progress
**Epic:** Pico-8 Platformer (G010) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** ไปถึง goal (flag) เพื่อชนะเกม หรือ dead → game over  
**เพื่อให้** ฉันมีความรู้สึก completion  

---

## ✅ Acceptance Criteria
1. [ ] Flag / goal marker อยู่ที่จุดสุ่งสุดของ level
2. [ ] Player ไปถึง flag → แสดง "Level Complete!" screen
3. [ ] Game Over screen เหมือน shmup (try again, menu)
4. [ ] ปุ่ม "Try Again" ทำงานได้
5. [ ] Game Over trigger: player health = 0 หรือ fall off screen

---

- [ ] Create Win screen with stats (coins collected, time)
- [ ] Create Game Over screen (health = 0)
- [ ] Add restart / menu buttons
- [ ] Test win and lose conditions thoroughly
