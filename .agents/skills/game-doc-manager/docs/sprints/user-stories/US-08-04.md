## ✅ Acceptance Criteria
1. [ ] แสดงข้อความ "All Pairs Matched!" เมื่อจบเกม
2. [ ] แสดง Total Moves ไม่สูงกว่าจริง (เป็น number)
3. [ ] แสดง Total Time ไม่สูงกว่าจริง (เป็น MM:SS)
4. [ ] คำนวณ Accuracy: (matched pairs) / (attempts) × 100%
5. [ ] แสดงเรติง: ⭐⭐⭐ (perfect), ⭐⭐ (good), ⭐ (ok)
6. [ ] ปุ่ม "Play Again" และ "Go to Menu" ทำงานได้
