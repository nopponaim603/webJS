# User Story: US-08-03 - Move Counter and Timer Display

**Status:** 🏗 In Progress
**Epic:** Card Memory Match (G008) - Sprint 01
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** ดูตัวนับการเลือกและนาฬิกาแบบ real-time ขณะเล่น  
**เพื่อให้** ฉันสามารถประเมินประสิทธิภาพของตนเองได้  

---

## ✅ Acceptance Criteria
1. [ ] แสดงตัวนับ "moves" (จำนวนครั้งที่คลิก) มุมบนซ้าย
2. [ ] แสดงนาฬิกานับถอยหลัง (seconds) มุมบนขวา
3. [ ] นาฬิกาเริ่มทำงานเมื่อคลิกใบคาร์ที่แรกเท่านั้น
4. [ ] ตัวนับ moves เพิ่ม 1 สำหรับการเลือกแต่ละครั้ง (ไม่ใช่การจับคู่)
5. [ ] Format นาฬิกาเป็น MM:SS
6. [ ] แสดงผลหน้าจอหน่อยบน (HUD) ไม่บดบัง gameplay

---

## 🛠 Technical Tasks (Git Log Updates)
- [ ] Create HUD sprite group in Phaser scene
- [ ] Implement move counter variable and increment on click
- [ ] Implement timer using Phaser.time.events (or setInterval)
- [ ] Format time string to MM:SS
- [ ] Position HUD elements with proper padding
- [ ] Test timer accuracy (no pause when cards flipping)
