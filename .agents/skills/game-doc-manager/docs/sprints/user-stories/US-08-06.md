# User Story: US-08-06 - Mobile-Responsive Touch Support

**Status:** 🏗 In Progress
**Epic:** Card Memory Match (G008) - Sprint 01
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่นที่ใช้สมาร์ทโฟนหรือแท็บเล็ต  
**ฉันต้องการ** เกมสามารถรับ input ได้ด้วยการ touch บนหน้าจอ  
**เพื่อให้** ฉันเล่นเกมได้บนอุปกรณ์พกพา  

---

## ✅ Acceptance Criteria
1. [ ] Touch event ทำงานแทน mouse click บนมือถือ
2. [ ] ขนาด card สัมพัทธ์กับหน้าจอ (responsive)
3. [ ] ไม่มีการหน่วง (lag) เมื่อคลิกบนมือถือ
4. [ ] ทั้ง portrait และ landscape ทำงานได้
5. [ ] ปุ่ม HUD ใหญ่พอสำหรับ touch (min 44×44px)
