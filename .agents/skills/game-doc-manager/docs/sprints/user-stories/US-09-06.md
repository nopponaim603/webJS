# User Story: US-09-06 - Lives System and Game Over Screen

**Status:** 🏗 In Progress
**Epic:** Pixel Shmup (G009) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** เกมมีระบบ lives 3 ชีพ และแสดง game over เมื่อตาย  
**เพื่อให้** ฉันสามารถลองใหม่และมีความรู้สึก challenge  

---

## ✅ Acceptance Criteria
1. [ ] ผู้เล่นมี 3 ชีพ (lives) แสดงผลใน HUD
2. [ ] ชีพถูกเสียเรื่อยๆ เมื่อชนศัตรูหรือถูกยิง
3. [ ] เมื่อ lives = 0 → แสดง "Game Over" screen
4. [ ] Game Over screen แสดง final score
5. [ ] ปุ่ม "Try Again" และ "Main Menu" ทำงานได้
6. [ ] Restart game จาก Game Over screen ได้
