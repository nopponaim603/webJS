# User Story: US-10-01 - Player Character with Gravity & Jump Physics

**Status:** 🏗 In Progress
**Epic:** Pico-8 Platformer (G010) - Sprint 02
**Owner:** Game Dev Team

---

## 📖 Description
**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** ควบคุมนักเล่นที่มีฟิซิกส์ gravity และการกระโดด  
**เพื่อให้** ฉันสามารถเคลื่อนที่และกระโดดเหนือ tile ได้  

---

## ✅ Acceptance Criteria
1. [ ] นักเล่นสามารถเคลื่อนที่ซ้าย/ขวา ด้วย arrow keys หรือ WASD
2. [ ] กด space / up arrow เพื่อกระโดด
3. [ ] นักเล่นถูกดึงด้วย gravity (acceleration)
4. [ ] ไม่สามารถกระโดดได้อีครั้งจนกว่าจะ landing (no double jump)
5. [ ] นักเล่นถูก draw ด้วย sprite จาก Pico-8 Platformer asset pack
6. [ ] Animation frames เมื่อเคลื่อนที่ และ standing still

---

- [ ] Enable arcade physics (gravity on body)

- [ ] Implement movement input (left/right key handling)
- [ ] Implement jump input with velocity.y
