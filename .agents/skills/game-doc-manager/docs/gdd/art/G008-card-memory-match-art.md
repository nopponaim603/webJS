# G008: Card Memory Match — Art Direction

**Version:** 1.0 | **Last Updated:** 2026-07-27

## Visual Style
- **Theme:** Classic card game aesthetic using Kenney Playing Cards Pack
- **Colors:** Green felt table background (#2d5a27) with gold accents
- **Animations:** Card flip with CSS/Phaser tween transitions
- **UI:** Clean, minimal HUD showing moves counter, timer, and match count

## Asset Requirements
- Kenney Playing Cards Pack (provided in project)
- Card back design (use Kenney's card back)
- Card values: A, 2-10, J, Q, K × 4 suits
- Grid layout: 4×4 (16 cards = 8 pairs)
