## 🚀 How to Run the Project locally

```bash
# 1. Clone repository
git clone https://github.com/nopponaim603/webJS.git
cd webJS

# 2. Run Custom Node.js HTTP Live Server
npm start
# or
node server.js

# 3. Open browser at http://localhost:5500
```
