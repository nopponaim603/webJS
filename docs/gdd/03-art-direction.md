# HTML5 Game Portfolio — Art & UI/UX Direction


---

## 1. Visual Style & Theme

- **Style Theme**: Modern Glassmorphism & Dark Mode Aesthetic
- **Primary Color Palette**:
  - **Background**: Deep Navy / Charcoal (`#0f172a`, `#1e293b`)
  - **Primary Accent**: Cyan Blue (`#00F2FE` → `#4FACFE`)
  - **Secondary Accent**: Vibrant Purple / Pink (`#A78BFA`, `#EC4899`)
  - **Card Backgrounds**: Glassmorphism (`rgba(255, 255, 255, 0.05)` with `backdrop-filter: blur(12px)`)

---

## 2. Typography Guidelines

- **Primary Font Family**: 'Inter', 'Prompt', 'Segoe UI', sans-serif
- **Headings**: Semi-bold to Bold (600-700) พร้อม Gradient Text Effects
- **Body Text**: Regular (400-500) อ่านง่าย สบายตา ความเข้มสี `#E2E8F0`

---

## 3. UI Components & Micro-interactions

1. **Game Cards**:
   - Aspect ratio เหมาะสมกับตัวเกม
   - Subtle hover zoom (`transform: translateY(-6px) scale(1.02)`)
   - Soft glow shadow on focus/hover
2. **Modal Overlay**:
   - Smooth Backdrop blur fade-in
   - Close button และ Control Bar โดดเด่น มองเห็นชัดเจน
3. **Category Badges & Search Bar**:
   - Rounded pill buttons (`border-radius: 9999px`)
   - Interactive active state ด้วยสี Cyan
