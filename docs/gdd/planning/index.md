# 📋 Planned Game Specifications — Roadmap & Proposals


---

## Overview

เอกสารในโฟลเดอร์นี้รวบรวมข้อเสนอและโครงร่างออกแบบเกม (Game Design Specifications) ที่ได้รับการวางแผนแนวคิดไว้เรียบร้อยแล้ว แต่ยังไม่ได้เริ่มเขียนโค้ดและสร้างซอร์สโค้ดใน `public/games/`

เมื่อเกมใดได้รับการพัฒนาจนเสร็จสิ้นและเปิดให้เล่นแล้ว เอกสาร GDD ของเกมนั้นจะถูกย้ายจาก `docs/gdd/planning/` ไปยัง `docs/gdd/games/` สอดคล้องกันทั้งระบบ
