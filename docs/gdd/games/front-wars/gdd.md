# Game Design Document (GDD) — FrontWars
## Real-Time Tactical Territory Domination Game

**ชื่อโครงการ (Project Title):** FrontWars  
**ประเภทเกม (Genre):** Real-Time Strategy (RTS) / Territory Control / IO Strategy  
**แพลตฟอร์ม (Platform):** Web Browser (HTML5 Canvas + Vanilla JavaScript)  
**เวอร์ชัน (Version):** 1.2  
**เจ้าของเอกสาร (Document Owner):** Antigravity Gamedev Team

## 1. บทนำและวิสัยทัศน์เกม (Introduction & Vision)

### 1.1 Elevator Pitch
**FrontWars** คือเกมวางแผนยึดดินแดนแบบเรียลไทม์ (Fast-Paced RTS) ในรูปแบบเว็บเบราว์เซอร์ ที่ได้รับแรงบันดาลใจจากความสนุกและพลวัตของเกม [frontwars.io](https://frontwars.io/) ผู้เล่นจะสวมบทบาทเป็นผู้บัญชาการทหารของ **สหพันธรัฐบลู (Blue Navy)** ในการทำสงครามช่วงแย่งชิงแผ่นดินกับมหาอำนาจอีก 3 ฝ่ายและแผ่นดินเป็นกลาง โดยต้องวางแผนบริหารสัดส่วนทหาร (Attack Ratio) สั่งเดินทัพ บุกยึดโหนดพื้นที่ (Provinces) และสร้างสิ่งปลูกสร้างยุทธศาสตร์ (เมือง, ป้อมปราการ, ท่าเรือ) เพื่อครอบครองพื้นที่โลกให้เกิน **70%**

### 1.2 จุดเด่นของเกม (Key Unique Selling Points)
1. **Fast-Paced Real-Time Combat:** การสู้รบและผลิตกำลังพลแบบรวดเร็ว จบเกมได้ภายใน 3-5 นาที
2. **Tactical Attack Ratio Selector:** ระบบปรับสัดส่วนการส่งทหาร (25%, 50%, 75%, 100%) เพื่อให้วางแผนรุก-รับได้อย่างมีกลยุทธ์
3. **Non-Blocking Tactical UI:** หน้าจอควบคุมที่ออกแบบตามหลัก Ergonomics - แถบสัดส่วนยึดครอง 100% ด้านบน และเมนูศูนย์บัญชาการใน Sidebar ทำให้พื้นที่แผนที่ Canvas โล่ง 100%
4. **Procedural Network Map:** แผนที่สุ่มโครงข่ายโหนด (Graph Connectivity) พร้อมสภาพภูมิประเทศที่หลากหลาย (ที่ราบ, ภูเขาสูง, ทางน้ำสมุทร)
5. **Zero-Asset Web Audio Synthesizer:** เอฟเฟกต์เสียงรบ สร้างเมือง และเอฟเฟกต์ชัยชนะสังเคราะห์ผ่าน Web Audio API โดยไม่ต้องดาวน์โหลดไฟล์เสียงภายนอก

## 4. ระบบแผนที่และภูมิประเทศ (Map Topology & Terrain)

### 4.1 กราฟเครือข่ายโหนด (Node Graph Structure)
- แผนที่สร้างจากโหนดยุทธบริเวณ (Province Nodes) ในรูปแบบโครงข่ายรังผึ้ง (Hexagonal Jittered Network)
- โหนดข้างเคียงจะถูกเชื่อมต่อด้วยเส้นกราฟ (Edge Connectivity) โดยทหารจะสามารถเดินทัพได้เฉพาะเส้นทางที่เชื่อมต่อกันเท่านั้น

### 4.2 ประเภทภูมิประเทศ (Terrain Types)
1. **ที่ราบ (Plains):**
   - ภูมิประเทศทั่วไป เคลื่อนทัพปกติ ไม่มีโบนัสป้องกัน
2. **ภูเขาสูง (Mountain):**
   - ภูมิประเทศทุรกันดาร มอบ **Defense Multiplier 1.4x** แก่ผู้ตั้งรับ
3. **สมุทร / ทางน้ำ (Water):**
   - เส้นทางน้ำข้ามเกาะ การส่งทหารผ่านทางน้ำต้องอาศัยโหนดต้นทางหรือปลายทางที่มี **ท่าเรือ (Port)**

## 5. ระบบการรบและการเดินทัพ (Combat & Movement Engine)

### 5.1 อัตราการบุก (Attack Ratio Selector)
ผู้เล่นสามารถปรับสัดส่วนจำนวนทหารที่จะส่งออกจากโหนดต้นทางได้ตลอดเวลา:
- **25%:** ส่งทหาร 1/4 ของที่มี (เหมาะสำหรับบุกหยั่งเชิง)
- **50%:** ส่งทหารครึ่งหนึ่ง (มาตรฐานการบุกสม่ำเสมอ)
- **75%:** ส่งทหาร 3/4 (สำหรับการรบหักห้ามใจ)
- **100%:** ส่งทหารทั้งหมดที่มีในโหนด (คงเหลือไว้เฝ้าเมือง 1 ทหาร)

### 5.2 การเคลื่อนทัพ (Troop Marching System)
- ทหารที่ถูกส่งออกจะรวมกลุ่มเป็นก้อนพลังงานเคลื่อนทัพ (Troop Orb) บนนเส้นทางกราฟ
- ความเร็วการเดินทาง: `speed = 0.012 * gameSpeed` (ปรับตามความเร็วเกม 1x, 2x, 4x)

### 5.3 สูตรคำนวณการรบ (Battle Formula)
เมื่อกองทัพผู้บุก ($A$) เดินทางถึงโหนดเป้าหมายของผู้ป้องกัน ($D$):

1. **คำนวณพลังป้องกันจริงของผู้ตั้งรับ ($P_D$):**
   $$P_D = \text{Troops}_D \times M_{\text{Defense}}$$
   *โดยที่ $M_{\text{Defense}} = 1.8$ หากมี Fortress หรือ $1.4$ หากเป็นพื้นที่ Mountain (ปกติ = 1.0)*

2. **ผลลัพธ์การรบ:**
   - **หาก $A > P_D$ (ผู้บุกชนะ):**
     - โหนดถูกเปลี่ยนผู้ครอบครองเป็นฝ่ายผู้บุก
     - จำนวนทหารคงเหลือใหม่ในโหนด:
       $$\text{Troops}_{\text{New}} = \max\left(1, \lfloor (A - P_D) \times 0.8 \rfloor\right)$$
     - เล่นเสียงชัยชนะ (Conquest Fanfare) + สร้างเอฟเฟกต์อนุภาคระเบิดสีประจำฝ่าย
   - **หาก $A \le P_D$ (ผู้ตั้งรับยันอยู่):**
     - โหนดยังคงเป็นของฝ่ายเดิม
     - จำนวนทหารผู้ป้องกันคงเหลือใหม่:
       $$\text{Troops}_D = \max\left(1, \left\lfloor \frac{P_D - A}{M_{\text{Defense}}} \right\rfloor\right)$$

## 6. ระบบสิ่งปลูกสร้างยุทธศาสตร์ (Infrastructure & Buildings)

ผู้เล่นสามารถเลือกอัปเกรดสิ่งปลูกสร้างในโหนดที่ตนเองครอบครองได้จากแผงศูนย์บัญชาการ:

| สิ่งปลูกสร้าง | ไอคอน | ค่าสร้าง (Troop Cost) | คุณสมบัติทางยุทธศาสตร์ |
|:---|:---:|:---:|:---|
| **City (เมืองใหญ่)** | 🏛️ | 30 ทหาร | เพิ่มอัตราผลิตกำลังพลจาก +1/วินาที เป็น **+3/วินาที** |
| **Fortress (ป้อมปราการ)** | 🛡️ | 40 ทหาร | เพิ่มเกราะป้องกันแผ่นดินเป็น **1.8 เท่า** ยันการบุกได้ดียิ่งขึ้น |
| **Port (ท่าเรือ)** | ⚓ | 35 ทหาร | เปิดเส้นทางเดินเรือข้ามสมุทรยึดครองพื้นที่เกาะหรือชายฝั่งไกลออกไป |

## 7. ปัญญาประดิษฐ์ศัตรู (AI Faction Engine)

AI ของทั้ง 3 ฝ่าย (Red, Green, Yellow) ทำงานผ่านรอบปฏิกิริยา (Loop Tick ทุก 1.5 วินาที) โดยมีตรรกะการตัดสินใจดังนี้:

1. **การวิเคราะห์ภัยคุกคามข้างเคียง (Neighbor Threat Assessment):**
   - AI สแกนโหนดข้างเคียงที่เชื่อมต่อกัน
   - หากโหนด AI มีทหาร > 20 นาย และโหนดข้างเคียงมีทหารน้อยกว่า 70% ของ AI -> **สั่งบุกทันที!**
2. **การเลือกพัฒนาสิ่งปลูกสร้าง (Infrastructure Investment):**
   - หากโหนด AI มีทหารสะสม > 50 นาย และไม่มีสิ่งปลูกสร้าง -> สุ่มสร้าง City (เพิ่มกำลังพล) หรือ Fortress (ตั้งรับ)

## 9. ระบบเสียงสังเคราะห์ (Web Audio Synthesizer Specs)

เกมใช้ **SoundEngine Class** สังเคราะห์รูปคลื่นเสียงแบบเรียลไทม์:
- **Select Sound:** Sine Wave 520Hz (0.08s)
- **Dispatch Sound:** Triangle Wave 340Hz -> 440Hz (0.1s)
- **Capture Fanfare:** Sine Sequence (440Hz -> 554Hz -> 659Hz -> 880Hz)
- **Loss Alarm:** Sawtooth Sequence (300Hz -> 260Hz -> 220Hz)
- **Build Structure:** Square Wave Arpeggio (600Hz -> 800Hz)
