# US-10-02: Zone Unlock Progression

**Epic:** Town Exploration  
**Owner:** Game Developer  
**Created:** 2026-08-19  
**Sprint:** Sprint 10  

---

## Description

ในฐานะผู้เล่น ผมปลดล็อกโซนเมือง 7 โซนตามความคืบหน้า — Town Square → School → Business → Art → Beach → Festival → Night Town — โดยต้องเก็บเลเวลและ/หรือทำ quest ของโซนที่มาแล้วก่อน

---

## Acceptance Criteria

- [ ] 7 โซนปลดล็อกตามลำดับ: Town Square → School → Business → Art → Beach → Festival → Night Town
- [ ] Town Square เปิดใช้งานเริ่มต้น (always available)
- [ ] โซนต่อไป unlock ตามข้อกำหนด (level req + coin req)
- [ ] แสดงข้อความ unlock (animation + "Zone Unlocked!")
- [ ] โซน unlock → navigate ได้ทันที
- [ ] Progress tracker แสดง % unlocked of total
- [ ] Progress persisted in LocalStorage

---

## Technical Tasks

1. สร้าง `ZoneProgression` system — unlock conditions per zone
2. Define unlock requirements (level 5 → School, level 10 → Business, etc.)
3. Add unlock check logic (compare current level to requirement)
4. Implement unlock animation (sparkle + text "Zone Unlocked!")
5. Update map to reflect unlocked status (locked/unlocked sprites)
6. Add progress tracker UI (percentage or checkpoint grid)
7. Persist progress state to LocalStorage
8. Test all 7 zone unlock progression end-to-end

---

## Dependencies

- US-10-01: Town Map Navigation (map displays unlocked zones)
- US-08-09: Level Progression (level unlocks zone)
- Kenney: City assets (zone markers, unlock effects)
- LocalStorage (progress persistence)

---

## Notes

- Zone unlock requirements (example):
  - Town Square: always open
  - School: Level 5 + 500 coins
  - Business: Level 10 + 2000 coins
  - Art: Level 15 + 4000 coins
  - Beach: Level 20 + 6000 coins
  - Festival: Level 25 + 8000 coins
  - Night Town: Level 30 + 10000 coins
- Consider: shop tier requirement too (optional)
