# US-09-01: Coin Economy System

**Epic:** Shop & Economy  
**Owner:** Game Developer  
**Created:** 2026-08-05  
**Sprint:** Sprint 09  

---

## Description

ในฐานะผู้เล่น ผมเก็บสะสมเหรียญจากการเก็บเลเวล match-3 และใช้เหรียญซื้ออัปเกรดร้านค้า โดยระบบจะเก็บถาวรและแสดงยอดรวมให้เห็นชัดเจน

---

## Acceptance Criteria

- [ ] ผู้เล่นได้รับเหรียญเมื่อทำเลเวล match-3 สำเร็จ (ตาม score)
- [ ] แสดงยอดเหรียญที่สะสมที่ HUD (มุมบนขวา)
- [ ] เหรียญถูกเก็บถาวรใน LocalStorage (ไม่หายเมื่อลูกรอง)
- [ ] ปุ่มร้านค้า (Shop button) เชื่อมต่อไปร้าน
- [ ] ผู้เล่นใช้เหรียญซื้ออัปเกรดในร้าน
- [ ] แสดง animation เมื่อได้เหรียญ (coin count up, sparkle)
- [ ] แสดง animation เมื่อใช้เหรียญ (coin count down, fade)
- [ ] Total coins earned tracked separately (lifetime)

---

## Technical Tasks

1. สร้าง `CoinManager` class — balance, earned, spent
2. Implement coin gain on level win (based on score/stars)
3. Add coin HUD display (large, readable, persistent)
4. Persist coin data to LocalStorage (on change)
5. Implement coin spend logic (deduct on purchase)
6. Add coin animation (count up/down, sparkle particles)
7. Add "Earned" counter (lifetime coins earned)
8. Test full flow: win level → get coins → spend → check balance

## Notes

- Coin reward formula: base + (score / 100) — e.g., 2000 score = 200 coins + 50 base = 250 coins
- Show coin balance in top-right HUD corner
- Coin animation: spawn coin sprites, float up, add to counter
- Coin spend: subtract from balance, show negative float
- Lifetime coins tracked separately (stats screen)
- Consider: minimum coin reward (never give 0)
