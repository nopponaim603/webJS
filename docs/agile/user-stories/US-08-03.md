## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ดูตัวนับจำนวนครั้งที่เปิดการ์ด (Moves) และเวลาที่ใช้เล่น (Timer) บนหน้าจอ  
**เพื่อให้** สามารถติดตามและประเมินประสิทธิภาพความจำในการเล่นเกมของตนเองได้  

---

## ✅ Acceptance Criteria

1. [ ] แสดงตัวนับจำนวนครั้งเปิดการ์ด (Moves Counter) เริ่มต้นที่ 0
2. [ ] แสดงตัวจับเวลา (Timer Display) รูปแบบ `MM:SS` เริ่มต้นที่ `00:00`
3. [ ] ตัวนับ Moves เพิ่มขึ้นทีละ 1 เมื่อเปิดการ์ดครบ 1 คู่ (1 Move = 2 Cards Opened)
4. [ ] Timer เริ่มเดินโดยอัตโนมัติเมื่อผู้เล่นคลิกเปิดการ์ดใบแรก
5. [ ] Timer หยุดทำงานทันทีเมื่อจับคู่การ์ดครบทั้ง 8 คู่ (Win Condition)
6. [ ] ตัว HUD แสดงผลชัดเจน ด้านบนของกระดานเกมโดยไม่บดบังตารางการ์ด

---

## 🛠 Technical Tasks

- [ ] สร้าง State สำหรับนับจำนวน Moves (`movesCount`)
- [ ] สร้าง State และ Timer Interval สำหรับนับเวลา (`timerInterval`, `secondsElapsed`)
- [ ] พัฒนาฟังก์ชัน `startTimer()`, `stopTimer()`, `resetTimer()`
- [ ] พัฒนาฟังก์ชัน `formatTime(seconds)` แปลงวินาทีเป็นรูปแบบ `MM:SS`
- [ ] อัปเดตการแสดงผลบน HUD Elements แบบ Real-time
- [ ] หยุดการทำงานของ Timer เมื่อเกมจบลง

## 🎨 HUD Design Specifications

- **Location:** ด้านบนของกระดานเกม (Top Center Layout)
- **Labels:** `Moves: 0` | `Time: 00:00`
- **Format:** `MM:SS` (เช่น `01:25`)
