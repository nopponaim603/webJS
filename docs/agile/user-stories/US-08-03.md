## ✅ Acceptance Criteria

- [ ] แสดงตัวเล่านับการตี (Move Counter) ตั้งแต่ตีแรก
- [ ] แสดงหน้าที่เล่นเกม (Timer) ตั้งแต่คลิกการ์ดใบแรก
- [ ] ตัวเล่าเพิ่มขึ้น 1 เมื่อคลิกการ์ดใบที่สอง (จับ 1 ตี)
- [ ] Timer เปิดขึ้นตั้งแต่คลิกการ์ดใบแรก
- [ ] Timer หยุดเมื่อจับได้ทุกใบ (Win)
- [ ] ไม่ต้องการแสดงที่จะเล่นเกมที่จะเล่น

## 🎨 Design Notes

### Move Counter
- เริ่มตั้งแต่การตีแรก
- หนึ่งการตี = 2 การคลิก (คลิกใบที่ 2)

### Timer
- เริ่มตั้งแต่คลิกการ์ดใบแรก
- หน่วย: นาที : วินาที (00:00)
- หยุดเมื่อจับได้ทุกใบ

### Display Position
- HUD อยู่ด้านบนของ game board
- มี 2 ตัว: "Moves: X" และ "Time: 00:00"
