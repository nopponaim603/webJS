## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** พื้นที่ต่อสู้ตรงกลางหน้าจอ (3 Play Slots) และแถบควบคุมคำสั่ง 3 ปุ่ม (`PLAY`, `TAKE`, `DISCARD`)  
**เพื่อให้** สามารถลากไพ่ลงไปวางต่อสู้ เลือกยืนยัน ยอมรับไพ่เข้ามือ หรือทิ้งไพ่ได้อย่างชัดเจน ตามโครงสร้าง Screen 3/4/7 ใน GDD

---

## ✅ Acceptance Criteria

1. [x] แสดงสล็อตวางไพ่ตรงกลางหน้าจอ 3 ช่อง (`3 Active Play Slots`) มีเส้นขอบเรืองแสงพร้อมรองรับการ Snap ไพ่
2. [x] แสดงกองไพ่สำรับ `[Deck]` และไพ่ข่ม (Trump Card) ที่มุมซ้ายบนของหน้าจอ
3. [x] แสดงแถบคำสั่ง Action Bar ด้านล่าง 3 ปุ่ม:
   - `PLAY` (สีฟ้า): ยืนยันการวางไพ่ต่อสู้
   - `TAKE` (สีแดง): เก็บไพ่บนโต๊ะทั้งหมดเข้ามือเมื่อแก้ทางไม่ได้
   - `DISCARD` (สีเหลือง/ส้ม): ทิ้งไพ่บนโต๊ะลงกองทิ้งเมื่อชนะรอบ
4. [x] รองรับการลากวางไพ่ (Touch / Drag & Drop) จากมือเข้าสู่ช่อง Play Slot

---

## 🛠 Technical Tasks

1. สร้างระบบ `PlayAreaZone` สำหรับตรวจสอบการ Drag & Drop และ Hit Detection ของสล็อต
2. สร้างส่วนประกอบ `ActionBarUI` ควบคุมสถานะเปิด/ปิดของปุ่ม `PLAY`, `TAKE`, `DISCARD`
3. เชื่อมต่อกติกาการเล่น (Durak Attack/Defend Battle Logic)
4. เพิ่มแอนิเมชันไพ่บินกลับเข้ามือเมื่อกด `TAKE` และแอนิเมชันไพ่หมุนบินทิ้งเมื่อกด `DISCARD`
