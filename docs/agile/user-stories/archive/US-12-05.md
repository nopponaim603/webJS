# US-12-05: Terrain Modifiers & Maritime Boat Transport

**Epic:** Epic 12 — WarFront.io Strategy Overhaul  
**Created:** 2026-08-12  
**Sprint:** Sprint 12  

---

## Description

ในฐานะผู้เล่น ผมได้รับผลประโยชน์จากคุณสมบัติภูมิประเทศ (Plains, Forest, Mountain, River) และสามารถส่งกองทัพลงเรือลำเลียงข้ามทะเลได้

---

## Acceptance Criteria

- [x] พื้นที่ Mountain เพิ่มพลังตั้งรับ 2.0x แต่เคลื่อนที่ช้าลง 0.4x
- [x] พื้นที่ Forest เพิ่มพลังตั้งรับ 1.35x และบังสายตาในหมอกควัน 75%
- [x] การข้ามแม่น้ำ (River) ลดพลังตั้งรับเหลือ 0.65x
- [x] การลำเลียงเรือ (Boat Transport) มีนับถอยหลัง Embark/Disembark
- [x] แสดงสไปรต์เรือแล่นบนผิวน้ำพร้อมเส้นทางเดินเรือ
