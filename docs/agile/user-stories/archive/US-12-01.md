# US-12-01: Core Engine & 60 FPS Ticker Integration

**Epic:** Epic 12 — WarFront.io Strategy Overhaul  
**Created:** 2026-08-12  
**Sprint:** Sprint 12  

---

## Description

ในฐานะผู้เล่น ผมต้องการเห็นระบบเกมรันลื่นไหลที่ 60 FPS บนเมานท์ของ WebGL/Canvas และโหลดไฟล์แผนที่ภูมิศาสตร์ได้อย่างถูกต้อง

---

## Acceptance Criteria

- [x] เกมรันด้วย Singleplayer Simulation Ticker Engine 60 FPS
- [x] โหลดไฟล์แผนที่ผ่าน MapCodec Binary Decoder หรือ JSON Fallback
- [x] แสดงขอบเขตภูมิภาค (Regions) และจุดสปอว์น Capital ของแต่ละ Faction ชัดเจน
- [x] มีระบบ Game Loop ที่ควบคุมจังหวะเวลาอย่างมีเสถียรภาพ (no tick drift)
- [x] รองรับทั้ง Desktop Browser และ Mobile Browser
