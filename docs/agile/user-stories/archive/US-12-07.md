# US-12-07: UI/UX, Hotkeys & Fog of War System

**Epic:** Epic 12 — WarFront.io Strategy Overhaul  
**Created:** 2026-08-12  
**Sprint:** Sprint 12  

---

## Description

ในฐานะผู้เล่น ผมสามารถใช้เมาส์ลากเลือกหลายพื้นที่ (Drag-Select), ใช้คีย์ลัดแป้นพิมพ์ และดูแผนที่ผ่าน HUD Overlay สไตล์ Glassmorphism

---

## Acceptance Criteria

- [x] รองรับการลากกล่อง Multi-Select ด้วยเมาส์/สัมผัส
- [x] คีย์ลัดแป้นพิมพ์: `Spacebar` (Pause), `A` (All Attack), `D` (Split 50%), `F` (Fortress), `P` (Port), `1-9` (Control Groups), `Tab` (Toggle Supply View)
- [x] HUD Overlay แสดง Faction Stats, Manpower, Region %, Minimap และ Battle Log
- [x] แสดงหมอกควันสงคราม (Fog of War) ที่ซ่อนข้อมูลศัตรูในพื้นที่นอกระยะสายตา
