# US-08-08: Ice Cream Flavors

**Status:** ✅ Done  
**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมต้องการเห็นไอเท็มบอลไอครีม 10 รสชาติต่างกัน โดยแต่ละรสมีสีและชื่อที่ชัดเจนและดี — เพื่อให้ match detection ทำงานได้ถูกต้อง

---

## Acceptance Criteria

- [x] มีไอเท็มบอล 10 รสชาติ (Flavors)
- [x] แต่ละรสชัดเจนด้วยสีที่แตกต่างกัน (colorful, distinct)
- [x] แต่ละรสมีชื่อ (ชื่อไอครีมตัวจริง: Vanilla, Chocolate, Strawberry...)
- [x] สีของบอลตรงกับชื่อ (e.g., Chocolate = brown, Strawberry = pink)
- [x] บอลทั้ง 10 แบบสามารถ spawn ได้ในกระดาน
- [x] Flavor data structure: {name, color, sprite, unlockLevel}
- [x] Flavor 1-5 เปิดใช้งานตอนเริ่มต้น, 6-10 เปิดตามเลเวล

---

## Technical Tasks

1. ออกแบบ `Flavor` data structure (name, color, sprite, unlockLevel)
2. Create flavor config array with 10 ice cream flavors
3. Load Kenney sprites for each flavor (Puzzle Pack 2)
4. Map sprite frames → flavor index
5. Implement flavor selection for random tile generation
6. Add flavor unlock system (10 unlock at level 30)
7. Display flavor legend/info on HUD
8. Test all 10 flavors render correctly

---

## Dependencies

- Kenney: Puzzle Pack 2 (ice cream ball sprites, 10 frames)
- Phaser 3 Image/Texture system
- US-08-01: Grid Display (tiles need flavors)
- US-08-03: Match Detection (flavor matching)

---

## Notes

- 10 flavors: Vanilla, Chocolate, Strawberry, Banana, Mango, Blueberry, Mint, Coconut, Caramel, Strawberry
- Each flavor = 1 sprite frame from Kenney Puzzle Pack 2
- Flavor unlock: Levels 1-5 unlock flavors 1-5, Level 30 unlocks all
- Color coding is critical for match-3 gameplay clarity
- Consider: add "locked" icon for locked flavors (levels 6-10)
