# User Story: US-17-02 - Top-Down Movement & Dual Controls

**Status:** ✅ Done  
**Epic:** [Epic 17 — Tiny Dungeon Survivor](../01-product-backlog.md)  
**Owner:** GameDev Team  

---

## 📖 Description
**ในฐานะ** ผู้เล่นทั้งบน PC และมือถือ  
**ฉันต้องการ** บังคับตัวละครเคลื่อนที่ในทิศทางต่างๆ ได้อย่างลื่นไหล  
**เพื่อให้** หลบหลีกฝูงมอนสเตอร์ในดันเจี้ยนได้อย่างแม่นยำ  

---

## ✅ Acceptance Criteria
1. [x] บังคับผ่านคีย์บอร์ด WASD / Arrow Keys ได้ 8 ทิศทาง
2. [x] แสดงผล Virtual Touch Joystick สำหรับหน้าจอมือถือ/สัมผัส
3. [x] กล้อง (Camera Follow) ติดตามตัวละครภายในขอบเขต Dungeon World Bounds (1400x1400 px)
