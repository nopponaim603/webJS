# US-G023-02: Sphere Physics Rolling & Controls

**Status:** ✅ Done  
**Epic:** Physics & Player Movement — BOBA PEARL DROP: 100% SUGAR (G023)  
**Owner:** Gameplay Programmer  
**Created:** 2026-08-12  
**Sprint:** Sprint 01  

---

## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** บังคับทิศทางการกลิ้งของเม็ดไข่มุกด้วย WASD / Arrow Keys / Virtual Joystick บนมือถือ และสามารถกดกระโดด Bounce (Spacebar) หรือ Turbo Dash (Shift)  
**เพื่อให้** สามารถควบคุมไข่มุกทรงตัวผ่านเส้นทางลอยฟ้า 3D ได้อย่างแม่นยำและสนุกสนาน

---

## ✅ Acceptance Criteria

1. [x] คำนวณทิศทางการกลิ้งแบบ Relative to Camera (กด W เคลื่อนที่ไปในทิศทางที่กล้องหันไป)
2. [x] มีความเร็วการกลิ้ง (Roll Speed), แรงหมุนทรงกลม (Angular Torque), และแรงต้านอากาศ (Linear Damping) ที่สมจริง
3. [x] สามารถกด `Spacebar` เพื่อกระโดดเด้งกลางอากาศ (Jump Bounce) พร้อมคูลดาวน์ 0.8 วินาที
4. [x] สามารถกดค้าง `Shift` เพื่อเร่งความเร็ว Turbo Dash พร้อมเอฟเฟกต์ Sugar Sparkle Particle ท้ายไข่มุก
5. [x] รองรับ Virtual Joystick และปุ่มสัมผัสบนมือถือ (Touch Overlay)
6. [x] ตรวจจับการตกลู่ (Fall-out Check `Y < -10`) และทำการ Reset เกิดใหม่ที่ Checkpoint ล่าสุด

---

## 🛠 Technical Tasks

1. เขียน `PlayerPhysicsController` คำนวณแรง Impulse จาก Keyboard Input และ Camera Forward/Right Vectors
2. คำนวณ Raycast Check หรือ Ground Collision เพื่อตรวจสอบว่าไข่มุกแตะพื้นอยู่หรือไม่ก่อนให้กระโดด
3. สร้าง Virtual Touch Joystick ด้วย HTML5/CSS สำหรับเบราว์เซอร์บนสมาร์ทโฟน
4. ใส่ระบบ Checkpoint Trigger เก็บตำแหน่งเกิดล่าสุดเมื่อผ่านแต่ละโซน
