## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ให้การแตะ ลาก และกดปุ่มมีเสียงตอบสนอง (SFX) และแรงสั่นระบบ Haptic Feedback พร้อมฉากฉลองการชนะ (Confetti & Coin Cascade)  
**เพื่อให้** สัมผัสถึงความน่าเล่น ความสนุก และรางวัลเมื่อชนะเกม ตามมาตรฐาน Juicy UX ใน GDD

---

## ✅ Acceptance Criteria

1. [x] มีระบบตอบสนองด้วย Haptic Vibration (`navigator.vibrate`) ในจังหวะ Hover (5ms), Drag (10ms), Snap (20ms), ชนะ (Success Pulse)
2. [x] มีระบบเสียงสังเคราะห์/ไฟล์เสียง (Web Audio API): เสียงสไลด์ไพ่, เสียงวางไพ่หนัก, เสียงปุ่มกด, และเสียงเหรียญ
3. [x] เมื่อชนะเกม แสดงป้าย Victory Drop พร้อมพลุกระดาษ (Confetti Burst) พุ่งกระจาย
4. [x] ตัวเลขนับเหรียญสะสม (Coin Counter) วิ่งไต่ขึ้นทีละนิดพร้อมเสียงคีย์สูงขึ้นตามจังหวะ

---

## 🛠 Technical Tasks

1. สร้างระบบ `HapticAudioManager` รวมศูนย์คำสั่ง Web Audio และ Vibration API
2. เขียนฟังก์ชันสร้างพลุกระดาษ Confetti ด้วย Canvas Particle System
3. สร้าง Number Ticker Animation สำหรับนับเงินเหรียญสะสมในฉากฉลอง
4. ทดสอบความเสถียรบนทั้ง Mobile Touch Screen และ Desktop Mouse Viewport
