# US-G022-04: Purple Shop Overlay & Card Draft System

**Status:** ✅ Done  
**Epic:** Progression & Economy — FOOL THE GAME (G022)  
**Owner:** Game Developer  
**Created:** 2026-08-12  
**Sprint:** Sprint 01  

---

## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** หน้าต่างร้านค้าการ์ดพาเนลสีม่วง (Purple Shop Overlay) ปรากฏขึ้นเมื่อจบแต่ละรอบการเล่น  
**เพื่อให้** สามารถนำเหรียญรางวัลที่สะสมมาเลือกซื้อการ์ดเสริมพลัง 3 ใบ หรือสุ่มใหม่ด้วยปุ่ม `RE-ROLL` ก่อนกด `NEXT` เข้าสู่รอบถัดไป ตามโครงสร้าง Screen 6/8 ใน GDD

---

## ✅ Acceptance Criteria

1. [x] พาเนลร้านค้าสีกราฟิกม่วง (Purple Panel) เลื่อน Slide-up ปรากฏขึ้นมาจากด้านล่างเมื่อจบ Wave
2. [x] แสดงตัวเลือกการ์ดเสริมความสามารถ 3 ใบ พร้อมป้ายราคา `$1`, `$2`, `$3`
3. [x] ปุ่ม `RE-ROLL` (สีเขียว): หักเหรียญเพื่อสุ่มรายการการ์ดในร้านใหม่
4. [x] ปุ่ม `NEXT` (สีแดง): ปิดหน้าร้านค้าและเริ่มแจกไพ่เข้าสู่ Wave ต่อไป
5. [x] เมื่อซื้อการ์ดสำเร็จ เหรียญจะถูกหักออกและมีเอฟเฟกต์การ์ดบินสะสมเข้าคอลเลกชัน

---

## 🛠 Technical Tasks

1. สร้างส่วนประกอบ `ShopOverlayUI` (Purple Glassmorphic Panel Container)
2. สร้างระบบ `EconomyManager` บันทึกเหรียญ (Coins), ดอกเบี้ย (Interest), และยอดคงเหลือ
3. สร้างคลาส `CardDraftPool` สำหรับสุ่มไอเท็มการ์ด 3 ใบจากบัฟ Common, Rare, Epic
4. เขียนฟังก์ชันสลับเปลี่ยนสกินและการ์ดความสามารถลงสำรับการเล่นของผู้เล่น
