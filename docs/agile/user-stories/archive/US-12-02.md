# US-12-02: Combat Physics, Morale & Casualty Formulas

**Epic:** Epic 12 — WarFront.io Strategy Overhaul  
**Owner:** Game Developer  
**Created:** 2026-08-12  
**Sprint:** Sprint 12  
**Status:** ✅ Done  

---

## Description

ในฐานะผู้เล่น ผมต้องการเห็นการปะทะกันของกองทัพคำนวณตามสูตรพลังการรบ ขวัญกำลังใจ และอัตราสูญเสีย เพื่อให้การยึดพื้นที่สมจริงและท้าทาย

---

## Acceptance Criteria

- [x] คำนวณพลังโจมตีและพลังตั้งรับด้วยสูตร `AttackPower` และ `DefensePower`
- [x] มีระบบขวัญกำลังใจ (Morale 0-100) ที่มีผลโดยตรงต่อพลังการรบ
- [x] อัตราความสูญเสีย (`Casualty Rate`) คำนวณแบบต่อ Tick การรบ
- [x] การพลิกยึดพื้นที่ (`Conquest Flip`) เกิดขึ้นเมื่อกำลังพลเข้าตีกระหน่ำมากกว่าเกณฑ์ 15%
- [x] เสียง SFX การปะทะและเอฟเฟกต์ระเบิด/การต่อสู้แสดงบนแผนที่
