# US-G023-03: Sugar Cubes Collectibles & Glassmorphism HUD

**Status:** ✅ Done  
**Epic:** Game Loop & UI — BOBA PEARL DROP: 100% SUGAR (G023)  
**Owner:** UI/UX & Gameplay Developer  
**Created:** 2026-08-12  
**Sprint:** Sprint 01  

---

## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** วางไอเทมก้อนน้ำตาล (Sugar Cubes 🧊) หมุนเรืองแสงกระจายตามด่าน ให้ผู้เล่นกลิ้งไปเก็บสะสมเพิ่ม Sugar Bar 0-100% บนหน้าจอ HUD  
**เพื่อให้** มีเป้าหมายในการเก็บสะสมคะแนนและเร่งระดับความหวานให้เต็ม 100% Sugar

---

## ✅ Acceptance Criteria

1. [x] สร้าง Mesh ก้อนน้ำตาล 3D (Sugar Cubes) สีขาวใสโปร่งแสง หมุนอยู่กลางอากาศ (Y-axis rotation animation)
2. [x] เมื่อเม็ดไข่มุกกลิ้งเข้าใกล้ก้อนน้ำตาล (Distance Check / Intersection) ก้อนน้ำตาลจะระเบิดเป็นอนุภาคดาว (Particle Burst) แล้วหายไป
3. [x] ทุกๆ ก้อนน้ำตาลที่เก็บได้ เพิ่ม Sugar Bar +10% และเพิ่มคะแนน +100 PTS
4. [x] หน้าจอ Glassmorphic HUD แสดงผลแถบ Sugar Bar %, นาฬิกาจับเวลา Speedrun (00:00.00), และปุ่มควบคุม/เมนู
5. [x] เมื่อ Sugar Bar เต็ม 100% จะแสดงเอฟเฟกต์ "100% SUGAR OVERLOAD!" เรืองแสงส่องสว่างบน HUD

---

## 🛠 Technical Tasks

1. สร้าง `CollectibleManager` สร้าง Sugar Cubes และ Golden Boba Bonus Items
2. เขียนระบบ collision detection ประสิทธิภาพสูง ตรวจสอบระยะห่างระหว่างไข่มุกกับน้ำตาล
3. สร้าง BabylonJS `ParticleSystem` รูปร่างดาว/ละอองน้ำตาลเมื่อเก็บสำเร็จ
4. สร้าง HTML/CSS Glassmorphism HUD overlay ซ้อนบน Canvas 3D
