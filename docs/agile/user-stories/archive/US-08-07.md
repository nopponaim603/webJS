## Description

ในฐานะผู้เล่น เมื่อผมทำ combo 4+ ไบล็อกติดกัน (horizontal/vertical) จะเกิด "Special Ball" ที่มี effect พิเศษ — ใช้สำหรับกวาดแถว/คอลัมน์/ที่นี้ที่นัน

## Acceptance Criteria

- [x] Special Ball เกิดเมื่อทำ 4+ same-flavor ในแถว/คอลัมน์
- [x] 2 แบบ special ball: Luma Ball (row clear) + Rainbow Ball (5+ clear)
- [x] Luma Ball: เมื่อ swap กับบอลที่เหมือนกัน → clear entire row
- [x] Rainbow Ball: เมื่อ swap กับบอลใดก็ตาม → clear all same-flavor tiles
- [x] Special Ball มี highlight animation (glow/pulse)
- [x] Effect animation ทำงานเมื่อใช้ special ball (screen clear + particle)
- [x] Special ball ไม่ถูกรับผลจาก match ธรรมดา (only trigger on swap)
