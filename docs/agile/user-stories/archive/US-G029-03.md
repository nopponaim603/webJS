## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** หน้าต่างอัปเกรดหลังจบ Wave (Wave Cleared Panel), จัดเรียงอาวุธใน Rack, อัปเกรดสกิลบนผัง Interactive SVG Tree และสามารถเซฟความคืบหน้า (Save State) เพื่อเล่นต่อได้  
**เพื่อให้** มีระบบ Progression และพัฒนาตัวละครได้อย่างต่อเนื่องในระยะยาว

---

## ✅ Acceptance Criteria

1. [x] แสดงผล Wave Cleared Panel พร้อมการคำนวณเหรียญที่เก็บได้, ค่าซ่อมแซมโดรน (Repair Cost) และเหรียญสุทธิ (Net Coins)
2. [x] ผังอัปเกรดแบบ Interactive 2D Pan/Zoom SVG Tree (`#tree-grid`, `#tree-edges`) สามารถคลิกซื้อ Perks/Nodes ได้
3. [x] ระบบจัดการ Weapon Rack รองรับการลาก/สลับตำแหน่งและถอดอาวุธได้ทั้งบนเมาส์และทัชสกรีน
4. [x] ระบบบันทึกข้อมูล (LocalStorage Persistence) สำหรับ Sector, Coins, Upgrades, Wave Level
5. [x] เชื่อมต่อเข้ากับ Game Hub Card (`src/app/page.js`) และ iFrame Modal ควบคุมเสียง/หน้าจอ Fullscreen

---

## 🛠 Technical Tasks

1. พอร์ตโค้ด `src/ui/testimonials.js`, Module Panels, และ SVG Tree Graph Renderer
2. สร้าง Data Layer จัดการ State ของ Run (Player Stats, Inventory, Coin Ledger)
3. พอร์ตระบบ Save/Load จาก LocalStorage พร้อม Migration check สำหรับ Safe Upgrades
4. ปรับแต่ง Audio Manager สำหรับสลับแทร็กเพลงตาม Wave และช่วงพักใน Menu
5. เพิ่ม Card เกมลงใน GameDevJS Hub พร้อม Category: 3D / Action Roguelike
