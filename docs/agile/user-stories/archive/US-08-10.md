# US-08-10: Mobile Touch Support

**Status:** ✅ Done  
**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่นที่ใช้มือถือ ผมสามารถใช้ touch controls (tap, swipe) ได้อย่างราบรี่นในการเล่น match-3 game โดยไม่มี latency หรือ input lag

---

## Acceptance Criteria

- [x] Tap/click ที่ tile → select tile (same as desktop mouse)
- [x] Tap adjacent tile → swap tiles
- [x] Tap tile → tap same tile → deselect
- [x] Touch input response ≤ 100ms (no lag)
- [x] ใช้ touch event (pointerdown/pointerup) ไม่ใช่ click (faster)
- [x] Mobile viewport meta tag: `width=device-width, initial-scale=1, user-scalable=no`
- [x] Tile hit area ≥ 44×44px (touch target minimum)
- [x] No accidental taps (prevent false triggers)

---

## Technical Tasks

1. Add `<meta name="viewport">` tag in index.html
2. Implement Phaser 3 `pointerdown`/`pointerup` input handlers
3. Add touch target size (44×44px minimum for mobile)
4. Test on iOS/Android emulator + real device
5. Fix any touch event conflicts (double-tap zoom, etc.)
6. Add `touch-action: none` CSS rule
7. Optimize input handling for mobile (reduce event listeners)
8. Test all 30+ levels on mobile viewport

---

## Dependencies

- US-08-01: Grid Display (touch on correct tiles)
- US-08-02: Ball Selection & Swap (tap-to-swap on mobile)
- Phaser 3 Input system (pointer events)
- HTML viewport meta tag

---

## Notes

- Use `pointerdown` (Phaser 3) instead of `click` for faster mobile response
- Disable double-tap zoom: `touch-action: none` on game container
- Add `user-scalable=no` in viewport meta
- Test on both portrait and landscape orientations
- Target touch area: 44×44px minimum (WCAG standard)
- Consider: swipe gestures for special actions (future)
