## Description

ในฐานะผู้เล่น ผมสามารถตัดสายส่งกำลังบำรุงของศัตรูเพื่อลดอัตราการเกิดประชากรและขวัญกำลังใจของพื้นที่ที่ถูกตัดขาดได้

## Acceptance Criteria

- [x] คำนวณเส้นทางเชื่อมต่อกลับไปยัง Capital Region หรือ Naval Port
- [x] พื้นที่ที่ถูกตัดขาด (Isolated Region) ถูกปรับลดอัตราการผลิตกำลังพล -60%
- [x] ขวัญกำลังใจของพื้นที่ Isolated ลดลงอย่างต่อเนื่อง (-2.0 /sec)
- [x] แสดงเส้นเชื่อมสายส่งกำลังบำรุงเมื่อกดปุ่ม Tab หรือเลือกดู Supply View Mode
