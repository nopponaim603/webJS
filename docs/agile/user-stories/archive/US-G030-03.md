## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** หน้าจอแสดงผล HUD มีตัวจับเวลาละเอียด (00:00.000), นับจุดผิดพลาด (Faults Counter), แถบความคืบหน้าสนาม (Track Rail), มาตรวัดความเร็ว (KM/H), ข้อมูล Telemetry, ระบบย้อนกลับ Checkpoint (R) และสถิติ Ghost Replay  
**เพื่อให้** สามารถฝึกฝนทำสถิติเวลาที่ดีที่สุดในการผ่านสนาม Canyon Works

---

## ✅ Acceptance Criteria

1. [x] แสดงผล HUD Plate ด้านบนซ้าย: นาฬิกาจับเวลา Millisecond + ตัวนับ Faults (X)
2. [x] แถบ Track Progress ด้านบนขวา แสดงตำแหน่งของตัวรถเทียบกับระยะทางและ Checkpoints ทั้งหมด
3. [x] หน้าจอ Speedometer และ Rev Bar ด้านล่างขวา
4. [x] ปุ่ม R ย้อนกลับไป Checkpoint ล่าสุดพร้อมเพิ่มแต้ม Fault +1
5. [x] หน้าต่าง Finish Summary (Time, Faults, Top speed, Air time, Best time) และบันทึกลง LocalStorage
6. [x] บันทึก Ghost Car Replay (คีย์บอร์ด G) และแสดง Telemetry Matrix (คีย์บอร์ด T)
7. [x] เพิ่มการ์ดเกม DIRT LINE ลงใน GameDevJS Hub (`src/app/page.js`) เปิดเล่นผ่าน Modal ได้สมบูรณ์

---

## 🛠 Technical Tasks

1. พอร์ตโค้ด DOM HUD Plate (`.plate`, `#track`, `#speed`, `#toast`, `#tele`)
2. สร้าง Checkpoint Trigger Collision System
3. บันทึก Time-series Ghost Telemetry Data (Position, Rotation, Velocity)
4. จัดการ Best Time Record และ LocalStorage Persistence
5. เพิ่ม Card เกมลงใน Game Hub พร้อม Tag: 3D / Physics / Racing
