# US-08-05: Score System

**Epic:** Core Gameplay — Match-3 Mechanics  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมต้องการเห็นคะแนนเพิ่มขึ้นเมื่อ match สำเร็จ โดยมี combo multiplier ที่เพิ่มขึ้นเมื่อทำ cascade หลายครั้งต่อกัน อย่างชัดเจนบนหน้าจอ

---

## Acceptance Criteria

- [x] คะแนนเพิ่มขึ้นเมื่อ match 3+ ไบล็อก (base score = 100 per tile)
- [x] Combo multiplier เพิ่มขึ้นเมื่อ cascade (x2, x3, x4...)
- [x] คะแนนรวมแสดงที่มุมบนขวาหน้าจอ (HUD)
- [x] แสดง combo text animation (x2, x3, x4...) เมื่อ cascade
- [x] คะแนนแสดงอย่างชัดเจน (font size ≥ 16px, readable)
- [x] Total score persist through level (save for win/lose screen)
- [x] แสดง score change animation (floating numbers + 100, +200)

---

## Technical Tasks

1. สร้าง `ScoreManager` class
2. Implement base score calculation (100 pts per tile in match)
3. Implement combo multiplier (x2 per cascade level, max x10)
4. Create HUD display for current score
5. Add floating score numbers (animated text "+100", "+200")
6. Add combo text display (x2, x3, x4...)
7. Connect score to match detection (score on match)
8. Store final score for win/lose condition check

## Dependencies

- US-08-03: Match Detection (score calculated per match)
- US-08-04: Gravity & Cascade (combo multiplier from cascades)
- US-08-06: Win/Lose Conditions (score as win condition)
- Phaser 3 Text/DisplayObject system
- Kenney: UI assets (HUD background)

---

## Notes

- Base score: 100 points per tile in the match (3 tiles = 300)
- Combo multiplier: x2 base, multiplied by cascade depth (max x10)
- Example: 3-match base 300, cascade 3 → 300 × 3 = 900
- Floating numbers: spawn at match position, float up, fade out
- Color-code combos: green (x2), yellow (x3), red (x4+)
- Score display: always visible in HUD, large enough for mobile
