## Description

ในฐานะผู้เล่น ผมได้ยิน sound effects เมื่อทำกิจกรรมต่าง ๆ ในเกม — select, swap, match, combo, win, lose — เพื่อเพิ่มความสนุกและความตื่นเต้น

---

## Acceptance Criteria

- [x] Select sound: เมื่อ tap เลือกบอล
- [x] Swap sound: เมื่อบอลสลับตำแหน่ง
- [x] Match sound: เมื่อ match สำเร็จ
- [x] Combo sound: pitch สูงขึ้นเมื่อ cascade
- [x] Win sound: Jingle สั้นๆ เมื่อชนะ
- [x] Lose sound: Jingle สั้นๆ เมื่อแพ้
- [x] Sound effects toggle (Mute/Unmute) ที่ HUD
- [x] Sound effects ไม่กระตุก/Delay (Web Audio API / OGG)

## Notes

- Level configs: targetScore formula = base + (level * increment)
- Moves formula: base moves - (level * decrement)
- Example: Level 1: 1000 pts / 30 moves, Level 10: 3000 pts / 25 moves
- Flavor unlock: Level 1 → 5 flavors, Level 5 → 7 flavors, Level 10+ → 10 flavors
- Level select: show 30 level icons, locked/unlocked states
- Progress persistence: save current level, stars, score in LocalStorage
