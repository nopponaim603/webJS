## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ได้ยินเสียงประกอบน่ารักๆ (เสียงเด้ง, เสียงเก็บน้ำตาล, เสียงตกถ้วยชา) หน้าสรุปดาวและคะแนนยามชนะด่าน และสามารถเลือกเล่นเกมนี้ได้จากหน้าเว็บรวมเกม (GameHub)  
**เพื่อให้** สัมผัสประสบการณ์การเล่นที่สมบูรณ์แบบ ลื่นไหล และเข้าเล่นได้สะดวกรวดเร็ว

## ✅ Acceptance Criteria

1. [x] สังเคราะห์เสียงประกอบด้วย Web Audio API (เสียงกลิ้ง, เสียงปิ๊งเก็บน้ำตาล, เสียง Boing กระโดด, เสียงฉลองชนะด่าน)

4. [x] เชื่อมต่อเกมเข้ากับ `src/app/page.js` และ `src/components/GameModal.jsx` ในหมวดหมู่ *"3D / กราฟิก"* และ *"อาร์เคด"*
