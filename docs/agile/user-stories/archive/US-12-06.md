# US-12-06: AI Bot Utility Matrix & 4 Personalities

**Epic:** Epic 12 — WarFront.io Strategy Overhaul  
**Created:** 2026-08-12  
**Sprint:** Sprint 12  

---

## Description

ในฐานะผู้เล่น ผมปะทะกับ AI Bots ที่มีการตัดสินใจอย่างฉลาดด้วยระบบ Utility Score Matrix และมีบุคลิกภาพเฉพาะตัว 4 รูปแบบ

---

## Acceptance Criteria

- [x] บอทคำนวณ Utility Score ตามน้ำหนักความอ่อนแอ, สายส่งกำลัง, ระยะเมืองหลวง และสิ่งปลูกสร้าง
- [x] มีบอท 4 บุคลิกภาพ: Aggressive Blitzkrieg, Tactical Expansionist, Turtle Fortifier, และ Naval Specialist
- [x] ปรับระดับความยากได้ 4 ระดับ: Easy, Normal, Hard, และ Nightmare
- [x] บอทเลเวลสูง (Hard/Nightmare) รู้จักรวมกลุ่มทัพและมุ่งตัดสายส่งกำลังบำรุง
