## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ให้การแจกไพ่มีแอนิเมชันพุ่งโค้งแบบเหลื่อมเวลา (Staggered Bézier Arc Deal) และมือถือไพ่ปรับตำแหน่งโค้งเป็นรูปพัดอัจฉริยะ (Adaptive Arc Fan Layout)  
**เพื่อให้** สัมผัสความลื่นไหลและฟีลลิ่งการจับไพ่ระดับพรีเมียม ตามข้อกำหนดของ GDD

---

## ✅ Acceptance Criteria

1. [x] ไพ่แจกออกจากกองสำรับ `[Deck]` มุมซ้ายบนพุ่งไปยังมือผู้เล่นและคู่แข่งด้วยวิถีโค้ง (Quadratic Bézier Path)
2. [x] มีเวลาเหลื่อมการแจก (Stagger Interval) `70ms - 100ms` ต่อใบ พร้อม Easing `Back.easeOut`
3. [x] คำนวณพิกัด $(X, Y)$ และมุมเอียง ($\theta$) ของไพ่ในมือตามจำนวนไพ่ที่มีอยู่ ($N$ ใบ)
4. [x] รองรับ 3D Card Flip (พลิกหมุนแกน Y) จากคว่ำเป็นหงายเมื่อไพ่เดินทางถึงมือผู้เล่น
5. [x] เมื่อมีการดึงไพ่ออกหรือแจกเพิ่ม ไพ่ใบที่เหลือจะสไลด์ปรับระยะห่างใหม่อย่างนุ่มนวล

---

## 🛠 Technical Tasks

1. สร้างคลาส `Card` สำหรับจัดการสถานะ พิกัด มุมหมุน หน้าไพ่ และแอนิเมชัน
2. สร้างคลาส `HandContainer` คำนวณสูตร Arc Fan Position ($\theta_i$, $X_i$, $Y_i$)
3. พัฒนาระบบ `DeckManager` จัดการการสับไพ่ (Shuffle) และสร้างลำดับการแจกไพ่
4. Implement Bézier Interpolation ใน Render Loop / Tween Sequencer
5. เพิ่มเงาลอยอากาศ (Air Shadow Offset) เพิ่มมิติระหว่างไพ่ลอยอยู่บนอากาศ
