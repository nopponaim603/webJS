## Notes

- Settings categories: Audio, Graphics, Accessibility
- Colorblind mode: toggle red-green filter (affects flavor colors)
- Graphics quality:
  - High: full effects, particles, transitions
  - Medium: no particle effects, smooth transitions
  - Low: no effects, minimal transitions
- Haptic: only on mobile (navigator.vibrate API)
- Text size: affect all UI text (HUD, menus, popups)
