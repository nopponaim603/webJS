# US-08-03: Match 3 Detection & Clear

**Status:** ✅ Done  
**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น เมื่อผม swap บอลแล้วเกิด 3+ บอลชนิดเดียวกันเรียงติดกัน (แนวนอน หรือ แนวตั้ง) — บอลเหล่านั้นจะถูก clear ออกจากกระดาน

---

## Acceptance Criteria

- [x] ตรวจหา match 3+ บอลชนิดเดียวกัน แนวนอน (horizontal)
- [x] ตรวจหา match 3+ บอลชนิดเดียวกัน แนวตั้ง (vertical)
- [x] Match 4 หรือ 5 บอลในแถวเดียวกันถูกตรวจจับถูกต้อง
- [x] บอลที่ match ถูก clear ออกจากกระดาน (animation fade out)
- [x] ถ้า swap แล้วไม่เกิด match → บอล swap กลับตำแหน่งเดิม (revert)
- [x] การ clear บอลทำพร้อมกันทุกกลุ่มที่ match ในรอบนั้น
- [x] เล่น sound effect สั้นๆ เมื่อ clear บอลสำเร็จพียงพอ (2 same adjacent = no match)
- [ ] ตรวจสอบทั้ง row และ column พร้อมกัน (simultaneous)
- [ ] แสดง animation เมื่อ match ถูกเอาออก (fade/scale out)
- [ ] ไม่ตรวจจับ match ของ special balls (แยก logic)

---

## Technical Tasks

1. สร้าง `MatchDetector` class
2. Implement horizontal scan — check each row for 3+ consecutive same-flavor
3. Implement vertical scan — check each column for 3+ consecutive same-flavor
4. Mark matched tiles (flag for removal)
5. Remove matched tiles from grid data
6. Add remove animation (scale down + fade out)
7. Update grid state after removal
8. Test edge cases (multiple matches at once)

---

## Dependencies

- US-08-02: Swap system (grid state must be updated after swap)
- US-08-01: Grid Display (tile types must exist)
- Phaser 3 Tween system (for remove animation)

---

## Notes

- Scan row-first then column (or both simultaneously)
- Special balls (luma, rainbow, bomb) — exclude from regular match logic
- ใช้ flag-based approach (mark → remove → animate)
- Consider cascade: after remove, gravity pulls balls down → new matches may form
