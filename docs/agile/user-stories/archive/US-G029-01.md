---

## 📖 Description

**ในฐานะ** ผู้พัฒนาเกม (Game Developer & Scraper)  
**ฉันต้องการ** ดึง static assets, Three.js modules, GLTF 3D models, BGM tracks, และ UI styles จากเกม SURVIVE 10 WAVES (`https://www.survive10waves.com/`)  
**เพื่อให้** สามารถนำโค้ดและทรัพยากรทั้งหมดมาจำลองและรันได้แบบ Offline-first ภายใน `public/games/survive-10-waves/`

---

## ✅ Acceptance Criteria

1. [ ] สแครปโครงสร้าง HTML5, ImportMap, และ CSS stylesheets ทั้ง 15+ ไฟล์ (`mod-tip.css`, `rack.css`, `controls.css`, `menu.css`, `testimonials.css` ฯลฯ)
2. [ ] ดาวน์โหลด Three.js vendor modules (`vendor/three/three.module.js`, `vendor/three/addons/`)
3. [ ] สกัดโมเดล 3D GLTF ตัวละครทหาร, ฝูงเอเลี่ยน, แผนที่อารีน่า, และอาวุธปืน
4. [ ] ดึง Audio tracks / Sound effects ที่ถูกกำหนดใน `src/config/tracks.js`
5. [ ] วางผังโครงสร้างโปรเจกต์แบบ ES Module ภายใต้ `public/games/survive-10-waves/` รันได้สมบูรณ์

---

## 🛠 Technical Tasks

1. ทำ Automated Scraper สำหรับ Fetch ทุก sub-path (`src/`, `assets/`, `vendor/`, stylesheets)
2. ปรับ ImportMap ให้รองรับ Local paths โดยไม่ต้องพึ่ง CDN ภายนอก
3. ตัด Simple Analytics tracker (`scripts.simpleanalyticscdn.com`) และ Cloudflare Beacon ออก
4. ตรวจสอบ GLTF/Texture loading paths ให้ทำงานแบบ Relative path
5. ทดสอบการรันผ่าน Local Node.js Web Server
