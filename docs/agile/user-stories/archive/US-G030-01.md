## 📖 Description

**ในฐานะ** ผู้พัฒนาเกม (Game Developer & Scraper)  
**ฉันต้องการ** ดึงโค้ด Single-file, Three.js engine bundle, GLTF loader, 3D Canyon track & Dirt Bike models จาก `https://dirtline.pages.dev/`  
**เพื่อให้** จัดโครงสร้างไฟล์สำหรับนำมารันและพัฒนาต่อบน Game Hub ภายใต้ `public/games/dirtline/`

---

## ✅ Acceptance Criteria

1. [ ] สแครป HTML, CSS Custom Properties (`--amber`, `--rust`, `--mono` ฯลฯ), และ Inlined Scripts จาก `https://dirtline.pages.dev/`
2. [ ] สกัด Vendor Three.js (`vendor/three.min.js`) และ GLTF / BasisU / Draco / Meshopt Loader extensions
3. [ ] สกัดโมเดล 3D สนามหุบเขา Canyon Works (Section 01), ตัวรถมอเตอร์ไซค์ และมวลนักขับ 3D Mesh
4. [ ] ดึง Audio assets / SFX เสียงเครื่องยนต์ 2 จังหวะ, เสียงเบรก และการกระแทกพื้น
5. [ ] รันในโฟลเดอร์ `public/games/dirtline/` แบบ Zero-external Dependency

---

## 🛠 Technical Tasks

1. สกัดโค้ด GLTFLoader r128 and materials extensions (Clearcoat, Transmission, BasisU)
2. จัดแยก Script ขนาดใหญ่ (~13,000+ บรรทัด) ออกเป็นโมดูลที่เป็นระเบียบ (`physics.js`, `track.js`, `hud.js`, `main.js`)
3. ดาวน์โหลดโมเดล Binary GLTF / KHR materials จาก URL assets
4. ตรวจสอบการโหลดบน Localhost HTTP Server
5. แก้ไข Path ให้เชื่อมโยงกับ `window.DIRTLINE_ASSETS = "./assets"`
