# US-09-04: Recipe Collection System

**Status:** ✅ Done  
**Epic:** Shop & Economy  
**Owner:** Game Developer  
**Created:** 2026-08-05  
**Sprint:** Sprint 09  

---

## Description

ในฐานะผู้เล่น ผมรวบรวมรีเซิปีไอครีมใหม่ๆ โดยผ่านเลเวลและชาเลนจ์ ที่จะเปิดใช้ในร้านค้าเพื่อเสิร์ฟลูกค้า

---

## Acceptance Criteria

- [x] มี 20+ รีเซิปีไอครีมที่สามารถรวบรวมได้
- [x] รีเซิปี 1-5 เปิดใช้งานตอนเริ่มต้น
- [x] รีเซิปี 6+ เปิดเมื่อทำเลเวล/ชาเลนจ์สำเร็จ
- [x] แสดงรีเซิปี collection ใน UI (grid view)
- [x] รีเซิปีที่ lock มี icon "lock" แสดง
- [x] รีเซิปี unlock → แสดง animation + sound
- [x] รีเซิปี unlock เชื่อมต่อกับ customer orders (unlock = playable)
- [x] รีเซิปี data: name, ingredients, flavor combo, unlock condition

---

## Technical Tasks

1. สร้าง `Recipe` data structure (name, ingredients, flavor, unlock)
2. Implement 20+ recipes with unique flavor combos
3. Add recipe unlock system (based on level/stars)
4. Create recipe collection UI (grid of locked/unlocked recipes)
5. Add unlock animation (sparkle + "New Recipe Unlocked!")
6. Connect recipes to customer orders (order uses unlocked recipes)
7. Add recipe info screen (tap recipe → see details)
8. Test unlock progression across levels

---

## Dependencies

- US-08-09: Level Progression (unlock based on level/stars)
- US-08-08: Ice Cream Flavors (flavors for recipes)
- US-09-03: Customer Service Mini-Game (customers order recipes)
- Kenney: UI sprites (recipe cards, lock icons)

---

## Notes

- 20+ recipes: different flavor combinations (e.g., Vanilla+Strawberry, Chocolate+Banana)
- Unlock progression: Level 1-5 → recipes 1-5, Level 5-10 → recipes 6-10, etc.
- Recipe display: grid of cards, locked/unlocked states
- Each recipe = 1-3 flavor layers (cone, ice cream, topping)
- Consider: recipe rarity (common, rare, legendary)
