1. [x] ระบบดาบหมุนเวียนรอบตัว (Orbiting Blades) ทำความเสียหายแก่ศัตรูที่เข้าใกล้

3. [x] ระบบมีดสั้นพิษ (Poison Darts) และสายฟ้าฟาด (Chain Lightning)
4. [x] แสดงตัวเลขความเสียหายลอยขึ้น (Floating Damage Text) และเอฟเฟกต์ศัตรูกระพริบแดงเมื่อโดนยิง
