## 📖 Description

**ในฐานะ** ผู้พัฒนาเกม (Game Developer & Scraper)  
**ฉันต้องการ** ดึงและแยกส่วน assets, 3D models, shaders, scripts, และ Vite bundle จากเกม GODAWFUL (`https://godawful.vercel.app/`)  
**เพื่อให้** นำโครงสร้างไฟล์ โมเดล 3D และโค้ดระบบมาถอดรหัส (Deconstruct) และจัดโครงสร้างลงใน `public/games/godawful/` ของ Game Hub ได้อย่างถูกต้อง

---

## ✅ Acceptance Criteria

1. [ ] สแครปไฟล์หลัก `index.html`, Manifest, Favicon และ CSS ทั้งหมดจาก `https://godawful.vercel.app/`
2. [ ] ดึง JS bundles จาก `assets/index-*.js`, `assets/three-*.js`, `assets/postfx-*.js` และถอด Source Map / Unbundle โค้ด
3. [ ] สกัดโมเดล 3D (GLTF/GLB), Textures, Sound SFX, และ Shaders/PostFX ทั้งหมด
4. [ ] จัดเก็บและจัดระเบียบโครงสร้างไดเรกทอรีลงใน `public/games/godawful/`
5. [ ] รันการแสดงผลบนสภาพแวดล้อม Local แบบ Offline-first ได้โดยไม่มีข้อผิดพลาด 404 ของ assets

---

## 🛠 Technical Tasks

1. ใช้ cURL / Fetch / Puppeteer เพื่อดาวน์โหลด Static Assets ทั้งหมดจากเป้าหมาย
2. แยก Vendor libraries (Three.js, Postprocessing) ออกเป็นโมดูลอิสระ
3. สกัด Shader materials และ Post-processing pipeline (Bloom, Vignette, Color grading)
4. ปรับ Asset paths ในโค้ดให้เป็น Relative path สำหรับรันบน Game Hub
5. ตรวจสอบ Security/CSP and Tracking scripts (counter.dev) และตัดส่วนที่ไม่จำเป็นออก
