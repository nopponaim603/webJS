# US-08-02: Ball Selection & Swap

**Epic:** Core Gameplay — Match-3 Mechanics  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมสามารถกดเลือกไอเท็มบอลบนกระดาน แล้วกดเลือกบอลที่อยู่ข้างเคียง (ขึ้น-ล่าง-ซ้าย-ขวา) เพื่อเปลี่ยนที่ทั้ง 2 บอล — เพื่อสร้าง match

---

## Acceptance Criteria

- [x] กดเลือกบอล (tap/click) เพื่อ select 1 บอล
- [x] บอลที่เลือกมี highlight animation (pulse/glow)
- [x] กดบอลที่อยู่ข้างเคียง (up/down/left/right) เพื่อ swap
- [x] Swap สำเร็จเมื่อ 2 บอลเปลี่ยนที่กันและกัน
- [x] Swap ที่ไม่ได้ผล (ไม่ adjacent) ไม่ทำงาน
- [x] Animation swap ราบรี่น (transition ≤ 300ms)
- [x] ป้องกัน swap ถ้าไม่ได้เลือกบอลก่อน

---

## Technical Tasks

1. สร้าง input handler สำหรับ tap/click บน tile
2. Implement tile selection state (selected/unselected)
3. Add selection highlight effect (tint + scale pulse)
4. Implement adjacency check (up/down/left/right)
5. Swap animation — tween position of both tiles
6. Validate swap — only adjacent tiles, only when one is selected
7. Add visual feedback (swap success/failure)
8. Test on mouse + touch input

---

## Dependencies

- US-08-01: Grid Display (tile objects must exist)
- Phaser 3 Input system
- Tween animation system

---

## Notes

- ใช้ Tween-based position swap (smooth animation)
- Swap logic เช็คกับ grid data (2D array) ก่อน render
- ป้องกัน swap ถ้าบอลไม่ adjacent หรือไม่มี selection
- Add cooldown/delay หลัง swap เพื่อป้องกัน spam
