# US-08-04: Gravity & Cascade

**Epic:** Core Gameplay — Match-3 Mechanics  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น เมื่อ match ถูกเอาออกจากกระดาน ไอเท็มบอลที่อยูด้านบนจะตกลงมาด้านล่าง (gravity) และมีไอเท็มบอลใหม่ถูกสร้างจากด้านบนเพื่อเต็มช่องว่าง — เปิดโอกาสสำหรับ cascade (match ต่อเนื่อง)

---

## Acceptance Criteria

- [x] ทุก tile ที่ไม่ได้ match จะตกลงมาด้านล่าง (gravity)
- [x] ตัวชี้วัด gravitational force = 1 tile per tick
- [x] ช่องว่างด้านบนถูกเต็มด้วยไอเท็มบอลใหม่ (random new tiles)
- [x] Animation ตก/เติม ราบรี่น (tween-based)
- [x] หลัง fall → เช็ค match อีกครั้ง (cascade chain)
- [x] Cascade อย่างน้อย 3 iteration (ตัวอย่าง: match → fall → new match → fall → new match)
- [x] มี visual feedback สำหรับ cascade (screen shake, glow)

---

## Technical Tasks

1. Implement gravity logic — iterate columns, move all non-empty tiles down
2. Fill empty top spaces with new random tiles from flavor pool
3. Add fall animation (tween position from new Y to target Y)
4. Detect new matches after fall (recursive match check)
5. Implement cascade loop (fall → detect → remove → fall → ...)
6. Limit cascade depth to prevent infinite loop (max 10-15 iterations)
7. Add visual effects for cascade (combo text, screen shake)
8. Test edge case: all tiles fall to bottom

---

## Dependencies

- US-08-03: Match Detection (removed tiles trigger gravity)
- US-08-02: Swap system (grid state must be consistent)
- US-08-08: Ice Cream Flavors (10 flavors for new tiles)
- Phaser 3 Tween system

---

## Notes

- ใช้ event-driven cascade (after gravity finishes, check match again)
- Maximum cascade: 10-15 iterations ต้อง break loop ได้ถ้าไม่มี match
- New tiles spawn at random positions above the grid
- Flavor pool weight: equal probability for all 10 flavors
- Consider: special ball triggers during cascade
