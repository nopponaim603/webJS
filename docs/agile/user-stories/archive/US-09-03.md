## Description

ในฐานะผู้เล่น ผมเสิร์ฟออเดอร์ให้ลูกค้า (Customer) ตามรีเซิปีที่เขาบอก โดยรับทิปเพิ่มเติมตามความเร็ว — มินิเกมเล่นได้หลังจากเก็บเลเวล match-3

---

## Technical Tasks

1. สร้าง `Customer` class (type, sprite, patience, order)
2. Implement 6 customer types with unique behaviors
3. Add customer queue system (spawn new customer after serve)
4. Implement order display (show order to player)
5. Implement serve logic (player selects → match order)
6. Add timer for each customer (patience meter)
7. Calculate tip based on speed (fast = 100%, slow = 50%, timeout = 0%)
8. Test full flow: customer arrive → order → serve → tip

## Notes

- 6 customer types: Regular, Happy, Impatient, Rich, Picky, Kid
- Each type has different patience/behavior:
  - Impatient: leaves faster, lower patience
  - Rich: tips more (2x normal)
  - Picky: only accepts specific recipes
- Patience timer: 10-15 seconds per customer
- Tip formula: speed ratio × base tip (100% if fast, 0% if timeout)
- Customer queue: max 3 in queue, spawn new after serve
