## Description

ในฐานะผู้เล่น ผมเห็น particle effects (sparkles, bubbles, confetti) และ animations ที่น่าพอใจสำหรับทุก action ในเกม — match, serve, upgrade, level up — ทำให้เกมดูสมบูรณ์และ rewarding

---

## Acceptance Criteria

- [x] Sparkle particles ใช้เมื่อ match สำเร็จ
- [x] Bubbles ใช้เมื่อ special ball เกิด
- [x] Confettiใช้เมื่อ win level
- [x] Star trail ใช้เมื่อ upgrade สำเร็จ
- [x] Score pop animations (floating numbers)
- [x] Ball pop animation (scale + fade)
- [x] Special ball effect animations (rainbow, bomb, explosion)
- [x] Particle count ≤ 50 per event (performance safe)
- [ ] All animations ≥ 30 FPS on mobile

---

## Technical Tasks

1. สร้าง `ParticleSystem` — manage all particle effects (pooling)
2. Implement sparkle effect on match (Kenney sparkle sprites)
3. Implement bubbles effect on special ball (Kenney bubble sprites)
4. Implement confetti on level win (Kenney confetti sprites)
5. Implement star trail on upgrade (Kenney star sprites)
6. Add score pop animation (floating numbers, Kenney text)
7. Add ball pop/special ball effect animations
8. Performance test: particle count, FPS, memory usage

## Notes

- Particle pooling: max 50 active particles per event
- Reuse particle sprites (don't create new ones per event)
- Auto-destroy particles after animation completes
- Use Kenney assets that are included in game assets
- Performance target: ≥30 FPS with all effects enabled
- Consider: particle intensity scales with combo level
