## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ฉาก 3D ที่สร้างด้วย BabylonJS มีแสงเงาอบอุ่น PBR Material ของเม็ดไข่มุกผิวมันวาว และกล้องติดตามตัวละครนุ่มนวล  
**เพื่อให้** สัมผัสถึงความน่ารัก สดใส และสวยงามของตัวละครไข่มุกตาม GDD

---

## ✅ Acceptance Criteria

1. [x] แสดงผล BabylonJS 3D Canvas แบบเต็มหน้าจอ (Full Responsive Container)
2. [x] สร้างเม็ดไข่มุก 3D (`Boba Pearl`) ด้วย PBR Material สีน้ำตาลชานมเข้ม ผิวมันวาว (ClearCoat + High Specular Highlight)
3. [x] ติดตั้งกล้อง `ArcRotateCamera` หรือ `FollowCamera` ที่ติดตามการเคลื่อนที่ของไข่มุกแบบ Smooth Damping 360°
4. [x] ติดตั้งแสง Directional Light พร้อม Soft Shadows และ Hemispheric Ambient Light โทนอบอุ่น
5. [x] เปิดใช้งาน `GlowLayer` เพิ่มความส่องสว่างนุ่มนวลของฉาก

---

## 🛠 Technical Tasks

1. สร้างโครงร่าง `public/games/boba-pearl-drop/index.html` และ `game.js`
2. โหลด BabylonJS 7.x library และ Babylon.js GUI / Audio
3. สร้าง `BobaGame Engine` Class สำหรับจัดการ Scene Lifecycle (`renderLoop`, `resize`)
4. กำหนดค่า PBR Material สำหรับ `bobaPearlMesh` ด้วยคุณสมบัติ `roughness = 0.15`, `metallic = 0.1`, `clearCoat.isEnabled = true`
5. เซ็ตค่ากล้องให้ตอบสนองกับการลากเมาส์ / ปัดหน้าจอเพื่อหมุนกล้องรอบตัวไข่มุก
