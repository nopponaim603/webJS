## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** หน้าแรก (Title Screen) ที่มีโลโก้ "FOOL THE GAME", ภาพการ์ดคลี่เป็นพัดโค้ง (Arc Fan Animation), และปุ่มเมนูสั่งการ  
**เพื่อให้** สามารถเริ่มต้นเข้าสู่เกมหรือออกจากเกมได้อย่างสะดวกสวยงาม ตามโครงสร้าง Screen 1 ใน GDD

---

## ✅ Acceptance Criteria

1. [x] แสดงชื่อเกม **"FOOL THE GAME"** บริเวณส่วนบนกลางหน้าจอด้วยฟอนต์สไตล์เรียบหรู
2. [x] แสดงภาพจำลองพัดไพ่ 5 ใบคลี่เป็นรูปพัดโค้ง (Arc Fan) ตรงกลางหน้าจอ พร้อมแอนิเมชันหายใจ (Breathing scale `1.0x -> 1.03x`)
3. [x] แสดงปุ่ม `PLAY` สีฟ้า (Blue Pill Button) สำหรับกดเข้าสู่เกม
4. [x] แสดงปุ่ม `QUIT` สีแดง (Red Pill Button) สำหรับปิดการทำงานหรือย้อนกลับ
5. [x] รองรับการแสดงผลแบบ Mobile Portrait Responsive (อัตราส่วน 9:16)
