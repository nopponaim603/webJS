## 🎨 Design Notes

### Score Calculation
```
Score = (Best Possible Time / Actual Time) × 1000
หรือ
Score = (Perfect Moves / Actual Moves) × 1000
```

### Rating (1-5 ดาว)
- 5 ดาว: น้อยกว่า 8 moves หรือ น้อยกว่า 30s
- 4 ดาว: 8-12 moves หรือ 30-60s
- 3 ดาว: 13-16 moves หรือ 61-90s
- 2 ดาว: 17-20 moves หรือ 91-120s
- 1 ดาว: เกิน 20 moves หรือ เกิน 120s

### Game Over Modal Content
```
🎉 ยินดี! เกมเสร็จสิ้น!

เวลา: 00:45
การตี: 12
แต้ม: 850
เรติงก์: ★★★★☆

[Play Again] [Back to Menu]
```
