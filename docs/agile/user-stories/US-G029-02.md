**Estimate:** L  

---

## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ควบคุมตัวละครทหารยิงต่อสู้กับฝูงเอเลี่ยน 10 Wave, มีโดรน Sentinel คอยคุ้มกัน, สลับปืนใน Weapon Rack และต้องวิ่งไปแท่น Extraction Pad ก่อนที่อารีน่าจะพังทลาย  
**เพื่อให้** สัมผัสประสบการณ์ Action Survival Shooter ที่ตื่นเต้นและเข้มข้น

---

## ✅ Acceptance Criteria

1. [ ] ผู้เล่นควบคุมการเดิน (WASD) และเล็งยิง 360° ด้วยเมาส์/สัมผัส (Crosshair System)
2. [ ] สลับปืน (Q / Right Click) จาก Weapon Rack พร้อมกระสุนและอัตรายิงต่างกัน
3. [ ] หุ่นโดรน Sentinel ช่วยยิงและมีแถบเลือดแยก (Drone HP / Damage / Repair)
4. [ ] ระบบคลื่นศัตรู 10 Waves พร้อมระบบ Arena Collapse (โซนบีบวงกลมลดขนาดลงเรื่อยๆ)
5. [ ] แท่นสกัดตัว (Extraction Pad) ทำงานเมื่อ Wave จบ ต้องยืนบนแท่นเพื่อเคลียร์ด่าน

---

## 🛠 Technical Tasks

1. เชื่อมโยง Game Engine Loop เข้ากับ Three.js Scene, Camera และ Particle Systems
2. พอร์ตระบบ Weapon System (Shotgun, Rifle, Plasma, Launcher) และ Hitbox Collision
3. พอร์ต AI พฤติกรรมฝูงเอเลี่ยน (Swarm Pathfinding, Aggro Range, Attack animations)
4. ติดตั้งวงแหวน SVG Arc HUD (`#en-arc`, `#ch-arc`, `#crosshair`) และ Floating Damage Numbers
5. ถอดรหัสระบบ Arena Collapse Barrier และฟังก์ชันนับถอยหลัง Wave Timer
