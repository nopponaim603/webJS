# US-08-01: Core Match-3 Grid Display

**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมต้องการเห็นกระดาน match-3 ขนาด 7×7 ที่แสดงไอเท็มบอลไอครีม (Ice Cream Ball tiles) ได้ชัดเจนและถูกต้อง ตามข้อกำหนดของ GDD

ผู้เล่นควรเห็นกระดานที่กริดขนาด 7×7 อย่างสมบูรณ์ โดยแต่ละเซลล์มีไอเท็มบอลไอครีมที่มีสีและรูปร่างต่างกัน 10 แบบ

---

## Acceptance Criteria

- [ ] กระดานแสดงกริด 7×7 (49 เซลล์) อย่างสมบูรณ์
- [ ] แต่ละเซลล์มีไอเท็มบอลไอครีม (Ice Cream Ball) แสดงอยู่
- [ ] ใช้สีและรูปร่างต่างกัน 10 แบบ (10 Flavors)
- [ ] การจัดวางตัวเริ่มต้นไม่มี match แรกก่อนเล่น (no initial matches)
- [ ] กริดแสดงตรงกลางจอ (centered) บน desktop และ mobile
- [ ] แสดง border/background ของกระดานชัดเจน

---

## Technical Tasks

1. สร้าง Scene `Match3Scene` ใน Phaser 3
2. ออกแบบ Grid config — row=7, col=7, tile size (64px desktop / responsive)
3. สร้าง `GridManager` class — handle grid data (2D array)
4. สร้าง `Tile` sprite — render ice cream ball with 10 flavor variants
5. Randomize initial grid placement (no 3+ same in row/col at start)
6. Add grid background + border visual
7. Add touch/mouse input handling basics (selection highlight)
8. Test on desktop + mobile viewport
