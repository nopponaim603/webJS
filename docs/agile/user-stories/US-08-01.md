## 📖 Description

## ✅ Acceptance Criteria

- [x] แสดงตารางการ์ด 16 ใบ (4×4) แบบ 2 คอลัมณ์
- [x] การ์ดทุกใบมีปก (back side) ซ่อนหน้าการ์ด
- [x] สุ่มการ์ด 8 คู่ (16 ใบ) ใหม่ทุกครั้งที่เริ่มเกม (Fisher-Yates shuffle)
- [x] ไม่มีการ์ดซ้ำกันนอกจากคู่ที่เหมือนกัน
- [x] การ์ดมีขนาดสม่ำเสมอและจัดเก็บเป็นตารางสม่ำเสมอ
- [x] มี flip animation เมื่อคลิกการ์ด (CSS 3D transform or Phaser tween)
- [x] การ์ดสามารถคลิกได้ทุกใบ (ไม่มี disabled cards)
- [x] รองรับ responsive บน mobile และ desktop

## 📐 Design Notes

### Grid Layout
- **Columns:** 4
- **Rows:** 4
- **Total Cards:** 16 (8 pairs)
- **Card Size:** Responsive (scales on mobile/desktop)
- **Spacing:** 8px between cards

### Shuffle Algorithm
- **Algorithm:** Fisher-Yates (Knuth) shuffle
- **Card Set:** 8 pairs of Kenney Playing Cards
- **Re-shuffle:** Every game start

### Flip Animation
- **Type:** CSS 3D transform (rotateY 180deg)
- **Duration:** 300ms
- **Easing:** ease-in-out
