## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ควบคุมรถมอเตอร์ไซค์วิบากด้วยระบบฟิสิกส์สมจริง โดยมีมวลคนขับ 72 kg บนสปริง, คันเร่ง (W), เบรกหน้า-หลัง (S), ถ่ายน้ำหนักเอนหลังยกล้อ (A) และก้มตัวลงหน้ารถ (D) รวมถึงการหมุนตัวกลางอากาศ  
**เพื่อให้** สัมผัสความท้าทายของเกม Trials Dirt Bike ที่ต้องอาศัยทักษะการทรงตัวและคุมน้ำหนักอย่างแม่นยำ

---

## ✅ Acceptance Criteria

1. [ ] ฟิสิกส์มวลนักขับ 72 kg (Rider Mass-on-Spring) โต้ตอบกับการเลี้ยวและการกระแทกอย่างสมจริง
2. [ ] ปุ่ม W (คันเร่ง / Throttle) ส่งแรงขับเคลื่อนไปยังล้อหลังพร้อมเอฟเฟกต์รอบเครื่องยนต์ (Rev Meter)
3. [ ] ปุ่ม S (เบรก / Front Bite Brakes) เบรกล้อหน้าทำให้หน้ารถทิ่มไปข้างหน้า
4. [ ] ปุ่ม A / D ถ่ายน้ำหนักหน้า-หลัง (Lean Weight) เพื่อยกล้อ (Wheelie) หรือกดหน้ารถลง
5. [ ] การควบคุมการหมุนและทรงตัวกลางอากาศ (Air Pitch Control) เมื่อรถลอยตัวพ้นพื้นดิน

---

## 🛠 Technical Tasks

1. พอร์ตอัลกอริทึม Dual-wheel Raycast Suspensions & Friction Curves
2. เชื่อมโยง Inverted Pendulum Physics สำหรับ Rider 72 kg Mass
3. จัดการระบบ Collision ระหว่างล้อรถ/โครงรถ กับพื้นผิว 3D Heightmap ของ Canyon Track
4. พอร์ตระบบ Rev / RPM Sound Synthesis & Visual Indicator
5. ปรับจูนค่า Gravity, Angular Damping, และ Spring Stiffness ให้ตอบสนองคมชัด 60 FPS
