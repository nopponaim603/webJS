## 🎨 Design Notes

### Reset Process
```
1. User clicks "New Game"
2. resetGame() called:
   - Shuffle card grid
   - Reset move counter to 0
   - Reset timer to 00:00
   - Reset all cards to FACE_DOWN
   - Close modal (if open)
```

### Button Positions
- **HUD:** "New Game" button at top/bottom of game board
- **Modal:** "Play Again" as primary button
