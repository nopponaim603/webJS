## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ควบคุมเทพก้อนเมฆ (Smug storm-cloud god) บินไปมารอบเมือง และใช้พลังสายฟ้า พายุ ฝน เพื่อสร้างความปั่นป่วนและทำลายสิ่งปลูกสร้างในเมืองน่ารัก  
**เพื่อให้** สัมผัสความสนุกของการเป็นเทพผู้เอาแต่ใจตาม Core Loop ของ GODAWFUL

---

## ✅ Acceptance Criteria

1. [ ] ผู้เล่นสามารถเคลื่อนย้ายเทพก้อนเมฆ (Cloud God) ตามเมาส์หรือการแตะสัมผัส (Pointer Controls) ได้อย่างลื่นไหล 60 FPS
2. [ ] ระบบพลังเทพ: เรียกสายฟ้า (Lightning Strike), พายุฝน (Rainstorm), ลมหมุน (Tornado) เพื่อโต้ตอบกับเมือง
3. [ ] ระบบฟิสิกส์การพังทลายของสิ่งก่อสร้าง (Building Deconstruction / Physics Destruction)
4. [ ] พฤติกรรมชาวเมือง (Townspeople AI) ตอบสนอง วิ่งหนี หรือตอบสนองต่อเหตุการณ์ภัยพิบัติ
5. [ ] ระบบคะแนนความเสียหาย (Chaos Score) หรือภารกิจประจำวันของเทพ

---

## 🛠 Technical Tasks

1. เชื่อมต่อระบบ Input (Mouse move, Click/Drag, Touch) เข้ากับตำแหน่ง 3D Raycasting ของก้อนเมฆ
2. พอร์ตระบบฟิสิกส์และ Particle System ของสายฟ้าและฝน
3. ถอดรหัสตรรกะ Town Mesh และ Destruction State (Hit detection & Swap to rubble mesh)
4. พอร์ต State Machine ของชาวเมือง (Idle, Wandering, Panic/Fleeing)
5. ปรับแต่ง Performance Loop ให้รองรับโมเดลและฟิสิกส์บน Mobile Web Browser
