# US-11-02: Sound Design & Audio

**Epic:** Polish & Launch  
**Owner:** Game Developer  
**Created:** 2026-09-02  
**Sprint:** Sprint 11  

---

## Description

ในฐานะผู้เล่น ผมต้องการฟัง sound effects สำหรับทุก action ในเกม — match, serve, upgrade, level up, coin — อย่างเหมาะสม และสามารถปรับ/ปิดเสียงได้

---

## Acceptance Criteria

- [ ] Sound effect สำหรับ match สำเร็จ (3+ match)
- [ ] Sound effect สำหรับ combo/cascade (x2, x3, x4+)
- [ ] Sound effect สำหรับ serve customer (success)
- [ ] Sound effect สำหรับ upgrade สำเร็จ
- [ ] Sound effect สำหรับ level win
- [ ] Sound effect สำหรับ level lose
- [ ] Sound effect สำหรับ coin gain/spend
- [ ] Sound effect สำหรับ special ball trigger
- [ ] Sound effect สำหรับ zone unlock
- [ ] Player สามารถปรับ volume ได้ (slider 0-100%)
- [ ] Player สามารถปิดเสียงได้ (mute toggle)
- [ ] All sounds ≤ 2s duration (fast feedback)
- [ ] No audio lag on mobile (preload + buffer)
