# US-08-09: Level Progression

**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมต้องการเดินทางผ่านเลเวล 30+ เลเวล โดยแต่ละเลเวลมีความยากเพิ่มขึ้น — target score เพิ่มขึ้น, moves ลดลง, flavor น้อยลง — และมีผลตอบรับเมื่อทำสำเร็จ

---

## Acceptance Criteria

- [ ] มีเลเวล 30+ เลเวลที่ playable
- [ ] แต่ละเลเวลมี target score ที่เพิ่มขึ้น
- [ ] แต่ละเลเวลมี moves ที่กำหนด (decreasing trend)
- [ ] Level 1-5 ใช้ flavor 1-5 (เริ่มต้นง่าย)
- [ ] Level 6+ ค่อย ๆ เปิด flavor ใหม่
- [ ] Level 30+ เปิดใช้ทุก flavor
- [ ] แสดง level number บน HUD
- [ ] Level progression แสดงที่ menu (level select screen)
- [ ] Win/lose → proceed to next level (win) or retry (lose)

---

## Technical Tasks

1. สร้าง `LevelConfig` data — 30+ levels with targetScore, moves, flavors
2. Implement level progression state (currentLevel, unlockedLevel)
3. Add level number display on HUD
4. Create level select screen (grid/list of levels)
5. Implement level unlock logic (clear level → unlock next)
6. Generate level configs (target score formula, moves formula)
7. Add "You Win" / "You Lose" → Next Level / Retry logic
8. Test 30+ level progression (end-to-end)

---

## Dependencies

- US-08-06: Win/Lose Conditions (level progression trigger)
- US-08-08: Ice Cream Flavors (flavor unlock per level)
- US-08-05: Score System (target score per level)
- Phaser 3 Scene system (level select scene)
- LocalStorage (progress persistence)

---

## Notes

- Level configs: targetScore formula = base + (level * increment)
- Moves formula: base moves - (level * decrement)
- Example: Level 1: 1000 pts / 30 moves, Level 10: 3000 pts / 25 moves
- Flavor unlock: Level 1 → 5 flavors, Level 5 → 7 flavors, Level 10+ → 10 flavors
- Level select: show 30 level icons, locked/unlocked states
- Progress persistence: save current level, stars, score in LocalStorage
