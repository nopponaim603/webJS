## 📖 Description

**ในฐานะ** ผู้เล่น Game Hub  
**ฉันต้องการ** ให้เกม GODAWFUL แสดงผลบนเว็บพอร์ตโฟลิโอ GameDevJS Hub มี HUD สวยงาม รองรับเสียง SFX/BGM และเล่นผ่าน iFrame Modal ได้อย่างไร้รอยต่อ  
**เพื่อให้** สามารถเปิดเล่นบนเว็บ Game Hub ได้ทั้งบนเดสก์ท็อปและมือถือ

---

## ✅ Acceptance Criteria

1. [ ] แสดงผล 2D UI Overlay (`#overlay-2d`, `#ui-root`) แบบ Responsive สอดคล้องกับ Game Canvas
2. [ ] เสียงสังเคราะห์ Web Audio API / SFX เสียงฟ้าผ่า ฝนตก เสียงชาวเมืองกรีดร้องอย่างสมบูรณ์
3. [ ] เพิ่มการ์ดเกม GODAWFUL บนหน้าแรก (`src/app/page.js`) พร้อมหมวดหมู่ 3D / Simulation
4. [ ] เปิดเล่นผ่าน iFrame Modal ได้อย่างลื่นไหล รองรับ Resize หน้าจอ และมีปุ่มปิด/รีสตาร์ตชัดเจน
5. [ ] มี Fallback เมื่อ WebGL2 ไม่พร้อมใช้งาน

---

## 🛠 Technical Tasks

1. สกัด CSS และ UI Layout จาก `#app`, `#game-canvas`, `#overlay-2d`, `#ui-root`
2. สร้าง Wrapper เชื่อม Web Audio SFX เข้ากับอีเวนต์ในเกม
3. เพิ่ม Metadata เกมใน `src/app/page.js` (Title, Category, Description, Thumbnail, Engine: Three.js)
4. ทดสอบ iFrame lifecycle (Focus, Blur, Mute audio on modal close)
5. ทดสอบ Responsive บนหน้าจอความละเอียดต่างๆ (360px - 4K)
