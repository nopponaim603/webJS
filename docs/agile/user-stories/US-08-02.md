## 🎨 Design Notes

### Card State Machine
```
Card State:
  1. FACE_DOWN (initial)
  2. FACE_UP (selected)
  3. MATCHED (face-up, locked)
  4. UNMATCHED (face-up briefly, then back to FACE_DOWN)
```

### Selection Logic
```
1. Player clicks Card A → Card A = FACE_UP
2. Player clicks Card B → Card B = FACE_UP
3. Check match:
   - If match → both cards = MATCHED
   - If no match → both cards flip back after 2s delay
4. Only 1 pair can be checked at a time
```

### Delay
- **Match:** Cards stay face-up immediately
- **Mismatch:** Cards flip back after 1500ms
