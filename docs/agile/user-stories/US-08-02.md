## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** คลิกการ์ดเพื่อเปิดดูหน้าไพ่ 2 ใบ และให้ระบบตรวจสอบความถูกต้องโดยอัตโนมัติ  
**เพื่อให้** รู้ว่าจับคู่ไพ่ถูกต้องหรือไม่ และดำเนินเกมต่อไปได้อย่างราบรื่น  

---

## ✅ Acceptance Criteria

1. [ ] ป้องกันการคลิกซ้ำซ้อนขณะกำลังเล่นแอนิเมชันพลิกการ์ด (Prevent Double Click)
2. [ ] รับ Click/Touch Events ได้อย่างแม่นยำทุกใบ
3. [ ] คลิกการ์ดใบแรก → แสดงแอนิเมชันเปิดหน้าการ์ด (Face Up)
4. [ ] คลิกการ์ดใบที่สอง → แสดงแอนิเมชันเปิดหน้าการ์ด + เริ่มตรวจสอบการจับคู่
5. [ ] กรณีจับคู่ถูกต้อง → การ์ดทั้งสองใบเปิดค้างไว้ (Matched State)
6. [ ] กรณีจับคู่ไม่ถูกต้อง → หน่วงเวลา 1.5 วินาที แล้วพลิกการ์ดกลับหน้าคว่ำ (Face Down)
7. [ ] ป้องกันไม่ให้ผู้เล่นคลิกการ์ดใบที่ 3 ขณะกำลังเปรียบเทียบผลจับคู่
8. [ ] เมื่อจับคู่ได้ครบทั้ง 8 คู่ → เรียกทำงาน Win Condition และเปิดหน้าต่างสรุปผล

---

## 🛠 Technical Tasks

- [ ] เขียน Event Handler สำหรับการเปิดการ์ด
- [ ] เพิ่ม Match Detection Algorithm เปรียบเทียบค่าไพ่ (Value/Suite)
- [ ] สร้าง Lock State ป้องกันการคลิกเกิน 2 ใบพร้อมกัน
- [ ] ตั้งเวลา Timeout หน่วงเวลา 1.5 วินาทีเพื่อพลิกการ์ดกลับกรณีจับคู่ผิด
- [ ] นับจำนวนคู่ที่เปิดสำเร็จ (Match Counter)
- [ ] เชื่อมโยงระบบเข้ากับ Win State เพื่อส่งค่าไปยังหน้าสรุปผล

## 🎨 State Machine Design

```text
[FACE_DOWN] -- (Click Card 1) --> [FACE_UP]
[FACE_UP]   -- (Click Card 2) --> [MATCH_CHECKING]
[MATCH_CHECKING] -- (Matched)   --> [MATCHED (Locked Open)]
[MATCH_CHECKING] -- (Mismatch)  --> (Wait 1.5s) --> [FACE_DOWN]
```
