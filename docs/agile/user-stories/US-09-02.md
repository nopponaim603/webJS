# US-09-02: Shop Tier Upgrades

**Epic:** Shop & Economy  
**Owner:** Game Developer  
**Created:** 2026-08-05  
**Sprint:** Sprint 09  

---

## Description

ในฐานะผู้เล่น ผมสามารถอัปเกรดร้านไอครีมผ่าน 5 Tier โดยใช้เหรียญ — Cart → Small Shop → Boutique → Grand → Megastore โดยแต่ละ Tier มีต้นทุนและ effect ที่แตกต่างกัน

---

## Acceptance Criteria

- [ ] มี 5 Tier: Cart → Small Shop → Boutique → Grand → Megastore
- [ ] แต่ละ Tier มีต้นทุนอัปเกรด (incrementally increasing)
- [ ] แสดง Tier ปัจจุบันของร้านที่หน้าจอ
- [ ] ปุ่ม Upgrade เปิดใช้งานเมื่อมีพอตั้ง (disable otherwise)
- [ ] Upgrade สำเร็จ → show animation (sparkles, building transform)
- [ ] Tier ที่สูงขึ้น → ผลต่อ: customer count, tip rate, revenue
- [ ] Tier 1 (Cart) เปิดใช้งานเริ่มต้น
- [ ] Tier 5 (Megastore) เปิดได้ต่อเมื่อ Tier 4 อัปเกรด

---

## Technical Tasks

1. สร้าง `ShopTier` data structure (name, cost, level, effect)
2. Implement 5 Tier costs (Cart=0, Small=500, Boutique=2000, Grand=5000, Mega=10000)
3. Add tier display on HUD/shop screen
4. Add upgrade button (enable/disable based on coins)
5. Implement upgrade logic (spend coins, increase tier)
6. Add upgrade animation (sparkle + building transform)
7. Add tier effect calculation (customer flow, tips, revenue)
8. Persist tier state to LocalStorage

---

## Dependencies

- US-09-01: Coin Economy System (coins for upgrading)
- Kenney: UI sprites (shop icons for each tier)
- Kenney: Puzzle Pack 2 (shop building sprites)
- LocalStorage (tier persistence)

---

## Notes

- Tier costs: Cart(0) → Small Shop(500) → Boutique(2000) → Grand(5000) → Megastore(10000)
- Each tier increases: base tip rate (+10%), customer flow (+20%)
- Tier icons: 5 different shop sprites from Kenney
- Upgrade animation: sparkle effect + building morph
- Consider: visual difference between tiers (size, detail, colors)
