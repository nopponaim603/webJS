# US-10-01: Town Map Navigation

**Epic:** Town Exploration  
**Owner:** Game Developer  
**Created:** 2026-08-19  
**Sprint:** Sprint 10  

---

## Description

ในฐานะผู้เล่น ผมเห็นแผนที่เมืองที่มี 7 โซน และ tap เพื่อ navigate ไปยังแต่ละโซน โดยโซนที่ปิดอยู่จะแสดงสถานะ "Locked"

---

## Acceptance Criteria

- [ ] แสดง Town Map ที่มี 7 โซน (Town Square, School, Business, Art, Beach, Festival, Night Town)
- [ ] แต่ละโซนเป็น interactive hotspot ที่ tap ได้
- [ ] โซนที่ปลดล็อก → tap → navigate ไปโซน (transition animation)
- [ ] โซนที่ lock → tap → show locked overlay (padlock icon + "Level X Required")
- [ ] Map มี background/scene ที่สวยงาม (Kenney assets)
- [ ] Navigation transition animation (fade/zoom/cut)
- [ ] Map persist state (progress, unlock status)

---

## Technical Tasks

1. สร้าง `TownMapScene` — render 7 zone hotspots on a map background
2. Load zone sprites/positions from Kenney assets (Plants Pack, City Pack)
3. Implement tap detection on zone hotspots
4. Add locked zone overlay (padlock icon, level requirement text)
5. Implement navigate logic (tap → tween/cut → enter zone scene)
6. Add transition animations (fade to black → load zone)
7. Add map UI (title, current location indicator)
8. Persist map state to LocalStorage

---

## Dependencies

- US-10-02: Zone Unlock Progression (which zones are unlocked)
- Kenney: City/Plants assets (map background, zone markers)
- Phaser 3 Scene system
- LocalStorage (map state)

---

## Notes

- 7 zones in order: Town Square (starter) → School → Business → Art → Beach → Festival → Night Town
- Each zone has unique background art (Kenney assets)
- Zone markers: small icons (Kenney: City Pack)
- Navigation: tap hotspot → zone scene loads (fade transition)
- Consider: map zoom/pan on larger screens
