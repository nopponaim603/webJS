# US-10-03: Dice Random Events

**Epic:** Town Exploration  
**Owner:** Game Developer  
**Created:** 2026-08-19  
**Sprint:** Sprint 10  

---

## Description

ในฐานะผู้เล่น ผมทอยเต้าเต้าส่วนเพื่อได้ event สุ่มที่ส่งผลต่อร้าน (bonus, penalty, surprise) — มีความหลากหลายและน่าติดตั้ง

---

## Acceptance Criteria

- [ ] มี 6+ event types (bonuses, penalties, surprises)
- [ ] Event types: Coin Bonus, Coin Loss, Free Move, Customer Surge, Special Item, Random Shop Upgrade
- [ ] ทอยเต้าส่วนได้ 1 ครั้ง/วัน (cooldown)
- [ ] Animation ทอยเต้าส่วน (dice roll, settle on face)
- [ ] Event result แสดงชัดเจน (text + icon + effect)
- [ ] Bonus: +coins, -moves (help player)
- [ ] Penalty: -coins, -shop (challenge player)
- [ ] Surprise: random outcome (exciting)

---

## Technical Tasks

1. สร้าง `DiceEvent` system — 6+ event types with outcomes
2. Implement dice roll animation (3D flip/settle)
3. Add event result screen (icon, text, coin change)
4. Implement event effects (coin bonus/loss, free move, etc.)
5. Add cooldown timer (once per day)
6. Add event history (last 5 events)
7. Integrate with coin/level systems (modify game state)
8. Test all event types produce correct effects

---

## Dependencies

- US-09-01: Coin Economy System (coin bonus/loss)
- Kenney: Dice assets (Kenney Dice Pack)
- Phaser 3 Animation system
- LocalStorage (cooldown/history)

---

## Notes

- 6 event types: Coin Bonus (+100-500), Coin Loss (-100), Free Move (+5 moves), Customer Surge (+1 customer), Special Item (random gift), Random Upgrade (1 random shop upgrade)
- Cooldown: 1 time per day (24 hours real-time or next login)
- Animation: 3D dice roll (Kenney dice sprite), settle on face
- Consider: "lucky" events (rare double bonus)
