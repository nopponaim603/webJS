## ✅ Acceptance Criteria

- [ ] Responsive layout สำหรับ mobile (360px+) และ tablet (768px+)
- [ ] Touch events ทำงานได้ถูกต้อง (ไม่ต้องใช้ click event ทับ)
- [ ] Card size ปรับอัตโนมัติตามหน้าจอ
- [ ] HUD (timer, moves, button) แสดงผลชัดเจนบน mobile
- [ ] Game Over modal จัดวางถูกต้องบน mobile
- [ ] ไม่มี UI clipping หรือ overflow
- [ ] Tested on Chrome DevTools mobile viewport

---

## 🛠 Technical Tasks

- [ ] เพิ่ม viewport meta tag (ถ้าใช้ vanilla HTML)
- [ ] ใช้ CSS media queries สำหรับ breakpoints
- [ ] ใช้ CSS responsive grid (min-width / flex wrap)
- [ ] ปรับ card size phone = 60-80px, tablet = 100-120px, desktop = 144px
- [ ] ทดสอบ on Chrome DevTools mobile viewport
- [ ] ทดสอบจริงบนมือถือ (ถ้ามี)

## 📐 Design Notes

### Breakpoints
| Device | Width | Card Size | Grid Gap |
|--------|-------|-----------|----------|
| Phone | 360-767px | 65-80px | 4px |
| Tablet | 768-1023px | 100-120px | 6px |
| Desktop | 1024px+ | 144px | 8px |

### CSS Approach
```css
/* Mobile first */
.card-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 4px;
  max-width: 360px;
  margin: 0 auto;
}

@media (min-width: 768px) {
  .card-grid {
    max-width: 480px;
    gap: 8px;
  }
}
```
