# US-08-06: Win/Lose Conditions

**Epic:** Core Gameplay — Match-3 Mechanics  
**Owner:** Game Developer  
**Created:** 2026-07-18  
**Sprint:** Sprint 08  

---

## Description

ในฐานะผู้เล่น ผมเห็นหน้าจอชนะ (Win Screen) เมื่อเก็บคะแนนถึง target score หรือหน้าจอแพ้ (Lose Screen) เมื่อจำนวนการเล่น (moves) หมดไป

ระบบจะแสดงผลที่ถูกต้อง และให้เลือกเริ่มเลเวลใหม่หรือเดินทางไปโซนเมือง

---

## Acceptance Criteria

- [ ] แสดง Win Screen เมื่อ score ≥ target score
- [ ] แสดง Lose Screen เมื่อ moves ≤ 0 โดยไม่ถึง target
- [ ] Win Screen แสดง: score ที่ทำได้, stars (1-3), ปุ่ม "Next Level"
- [ ] Lose Screen แสดง: score ที่ทำได้, ปุ่ม "Try Again", ปุ่ม "Menu"
- [ ] ปุ่ม Next Level → ไปเลเวลต่อไป (level n+1)
- [ ] ปุ่ม Try Again → re-play level เดิม (same config)
- [ ] Target score และ moves แสดงที่ HUD ก่อนจบบท
- [ ] Animations สำหรับ win/lose transitions

---

## Technical Tasks

1. สร้าง Win Scene — display score, stars (1-3), Next Level button
2. สร้าง Lose Scene — display score, Try Again button, Menu button
3. Implement win condition check (score ≥ target)
4. Implement lose condition check (moves ≤ 0)
5. Add HUD display for target score and remaining moves
6. Calculate stars based on score (≥80% = 3 stars, ≥60% = 2, ≥40% = 1)
7. Add transition animation (fade between scenes)
8. Connect to level progression (Next Level → scene change)

---

## Dependencies

- US-08-05: Score System (score value needed)
- US-08-09: Level Progression (target score per level)
- Phaser 3 Scene system (scene switching)
- Kenney: UI assets (button sprites)

---

## Notes

- Win condition: score ≥ target_score (config per level)
- Lose condition: moves ≤ 0 (moves decrease per swap, configurable per level)
- Stars system: 3 stars = best (≥80% target), 2 stars (≥60%), 1 star (≥40%)
- Target score increases per level (e.g., Level 1: 1000, Level 5: 3000)
- Moves decrease: 1 move per swap (configurable, e.g., 2 moves per swap)
