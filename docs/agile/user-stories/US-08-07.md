## ✅ Acceptance Criteria

- [ ] Game loads in <2 seconds (first load)
- [ ] Static assets preloaded (images, sprites)
- [ ] Asset lazy loading ที่เหลือ
- [ ] No FPS drops during gameplay (target 60fps)
- [ ] Memory usage < 50MB
- [ ] Asset caching with Cache-Control headers
- [ ] Use appropriate image sizes (144px for desktop)
- [ ] Game assets are root-relative path (/assets/...)

---

## 🛠 Technical Tasks

- [ ] Preload card images on game initialization
- [ ] Use Kenney card assets 144px for faster loading
- [ ] Add image compression (ถ้าจำเป็น)
- [ ] Use CSS will-change for better GPU utilization
- [ ] Optimize flip animation (use transform: rotateY, not width/height)
- [ ] Add loading indicator (optional)
- [ ] Lazy load non-critical assets
- [ ] Asset path verification (all /assets/kenney_... paths work)

## 🎨 Design Notes

### Asset Loading Strategy
| Asset | Loading | Priority |
|-------|---------|----------|
| Card Back | Preload (sync) | High |
| Card Faces (8 pairs) | Preload (async) | High |
| Sound Effects | Lazy load | Low |
| Background | Inline CSS gradient | Low |

### Optimization Tips
- Use `transform: rotateY` instead of `transform: rotate` 
- Use `will-change: transform` on card elements
- Use CSS `backface-visibility: hidden`
- Asset versioning with cache busters
