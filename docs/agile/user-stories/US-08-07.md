## 📖 Description

**ในฐานะ** ผู้เล่นเกม  
**ฉันต้องการ** ให้เกมตอบสนองเร็ว โหลดไฟล์ภาพการ์ดได้อย่างรวดเร็ว และเล่นได้อย่างลื่นไหล  
**เพื่อให้** ได้รับประสบการณ์การเล่นเกมที่ดีที่สุด ปราศจากการกระตุกหรือการรอโหลดภาพ  

---

## ✅ Acceptance Criteria

1. [ ] โหลดเข้าสู่เกมได้รวดเร็วภายใน 2 วินาทีในการเปิดครั้งแรก
2. [ ] มีการ Preload ไฟล์ภาพการ์ด (Card Back & Card Faces) ก่อนเริ่มเกม
3. [ ] อัตราการแสดงผลลื่นไหลที่ระดับ 60 FPS ตลอดการเปิดพลิกการ์ด
4. [ ] ใช้หน่วยความจำ (Memory Usage) น้อยกว่า 50MB
5. [ ] เลือกใช้ขนาดรูปภาพที่เหมาะสม (144px / 240px จาก Kenney Pack) ไม่ใช้ภาพขนาดใหญ่เกินจำเป็น
6. [ ] เส้นทางไฟล์ Assets เป็นแบบ Relative Path อย่างถูกต้อง

---

## 🛠 Technical Tasks

- [ ] เขียนฟังก์ชัน Preload รูปภาพการ์ดทั้ง 8 คู่และหลังการ์ดก่อนเรนเดอร์ Grid
- [ ] ใช้ประโยชน์จาก CSS `will-change: transform` และ `backface-visibility: hidden` เพื่อเร่งความเร็วด้วย GPU
- [ ] ตรวจสอบว่าเลือกใช้ขนาดไฟล์รูปภาพจาก Kenney Pack ขนาด 144px เพื่อประหยัด Bandwidth
- [ ] ตรวจสอบโครงสร้างไฟล์เพื่อป้องกันปัญหา Resource Path ใน Iframe Modal Container

## 📐 Optimization Guidelines

```css
/* GPU Acceleration for Card Flip */
.card-inner {
  transition: transform 0.3s ease-in-out;
  transform-style: preserve-3d;
  will-change: transform;
}

.card-front, .card-back {
  backface-visibility: hidden;
}
```
