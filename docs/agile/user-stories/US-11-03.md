# US-11-03: Daily Rewards & Streak

**Epic:** Polish & Launch  
**Owner:** Game Developer  
**Created:** 2026-09-02  
**Sprint:** Sprint 11  

---

## Description

ในฐานะผู้เล่น ผมรับรางวัลรายวัน (Daily Rewards) เมื่อ login วันละครั้ง และได้ streak bonus หาก login ต่อเนื่องหลายวัน

---

## Acceptance Criteria

- [ ] รับรางวัลรายวันได้ 1 ครั้ง (login trigger)
- [ ] รางวัลรวม 7 วัน (Mon-Sun daily rewards)
- [ ] วัน 1: 50 coins, วัน 2: 100 coins, วัน 3: 200 coins, วัน 4: 300 coins, วัน 5: 500 coins, วัน 6: 750 coins, วัน 7: 1000 coins
- [ ] Streak bonus: ถ้าต่อเนื่อง 7 วัน ได้ bonus 2000 coins
- [ ] Streak break: ถ้าไม่ login 1 วัน → streak reset
- [ ] แสดง popup เมื่อ login → claim button → claim reward
- [ ] แสดง streak counter (days remaining)
- [ ] Claimed status persist (cannot claim twice/week)

---

## Technical Tasks

1. สร้าง `DailyReward` system — track login dates, streak count
2. Implement 7-day reward schedule (coins per day)
3. Implement streak counter (consecutive days)
4. Implement streak break logic (miss a day = reset)
5. Add login detection (check last login timestamp)
6. Add claim popup UI (show rewards, claim button)
7. Add claim animation (coin count up, sparkle)
8. Persist streak data to LocalStorage

## Dependencies

- 7-day schedule: Mon 50, Tue 100, Wed 200, Thu 300, Fri 500, Sat 750, Sun 1000 + 2000 streak bonus

- Consider: "missed day" penalty or "try again tomorrow" message
