# User Story: US-02-games — Multi-Game Suite Integration

**Status:** ✅ Done  
**Epic:** [Product Backlog](../01-product-backlog.md)  
**Owner:** Dev Team  

---

## 📖 Description

**ในฐานะ** ผู้เล่น  
**ฉันต้องการ** มินิเกมทั้ง 3 เกม (Emoji Match, 2048 Cubes, Tile Match) ที่เล่นได้อย่างสมบูรณ์  
**เพื่อให้** ได้รับความบันเทิง ความท้าทาย และความเพลิดเพลินจากการเล่นเกมหลากรูปแบบ  

---

## ✅ Acceptance Criteria

1. [x] **Emoji Match**: เปิดการ์ดจับคู่อีโมจิที่เหมือนกัน แข่งกับเวลา แสดงผลรวมคะแนน
2. [x] **2048 Cubes**: เล็งยิงลูกบาศก์ รวมค่าตัวเลข 2x เมื่อชนกันตามกฎฟิสิกส์
3. [x] **Tile Match**: เลือกไทล์ลงถาด 7 ช่อง จับคู่ไทล์ที่เหมือนกัน 3 ใบ
4. [x] ทุกเกมสามารถรันแบบ standalone ผ่านเบราว์เซอร์ และรันใน Modal Iframe ได้อย่างไร้ปัญหา
